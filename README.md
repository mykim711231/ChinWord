# ChinVoca 中国语

북경 표준어(普通话) 실생활 어휘·고사성어 학습 PWA

## 개요

- **목적**: 상황별·주제별 중국어 단어와 고사성어를 학습하는 프로그레시브 웹 앱
- **대상**: 일반인 학습자 (HSK 1~6급 수준)
- **배포**: GitHub Pages — URL만으로 접근, 앱스토어 불필요
- **핵심 기능**: 오프라인 학습, TTS 발음 듣기, 필순 애니메이션, Leitner SRS 복습

## 콘텐츠 구성

| 단계 | 상황별 단어 (18그룹) | 고사성어 (9그룹) |
|------|---------------------|-------------------|
| Phase 1: 기초 | 인사·소개, 가족·친구, 교통·이동, 식당·음식, 쇼핑·흥정, 숙박·호텔 | 학습과 노력, 인간관계, 처세와 지혜 |
| Phase 2: 중급 | 병원·약국, 직장·비즈니스, 학교·교육, 여행·관광, 날씨·계절, 취미·여가 | 시간과 인생, 감정과 마음, 성공과 실패 |
| Phase 3: 고급 | 비즈니스 회의, 무역·계약, 금융·은행, IT·기술, 법률·행정, 부동산·주거 | 경영과 리더십, 경제와 재물, 사회와 세태 |

- **총계**: 440개 단어 + 72개 고사성어
- **단어 정보**: 한자, 병음, 품사, 한국어 뜻, 한자 풀이(부수+구성), HSK 등급
- **성어 정보**: 한자, 병음, 한국어 뜻, 유래, 글자별 풀이, 유의어, 출전

## 기술 스택 (예정)

| 계층 | 기술 |
|------|------|
| 프레임워크 | Vite + React 18 + TypeScript |
| 스타일링 | TailwindCSS |
| 상태 관리 | Zustand |
| PWA | vite-plugin-pwa + Workbox |
| TTS | Web Speech API |
| 필순 | hanzi-writer |
| 검색 | MiniSearch |
| 복습 | Leitner 5-Box SRS |
