# 학교와 교육 (学校与教育, Xuéxiào yǔ jiàoyù)

> 상황: 수업, 시험, 캠퍼스 생활
> 수준: HSK 1~3급 중심
> 단어 수: 25개

---

### 1. 学校 / xuéxiào / [명사] / 학교

- 한자 풀이:
  - 学: 冖(덮을멍) + 子(아들자) → 배우다
  - 校: 木(나무목) + 交(사귈교) → 학교
- HSK 등급: 1급

---

### 2. 学生 / xuésheng / [명사] / 학생

- 한자 풀이:
  - 学: 冖(덮을멍) + 子(아들자) → 배우다
