# 병원과 약국 (医院与药店, Yīyuàn yǔ yàodiàn)

> 상황: 증상 설명, 진료, 약 구매
> 수준: HSK 2~3급 중심
> 단어 수: 25개

---

### 1. 医院 / Yīyuàn / [명사] / 병원

- 한자 풀이:
  - 医: 匚(상자방) + 矢(화살시) → 화살을 상자에 넣어 치료하다, 의료
  - 院: 阝(좌부변) + 完(완전할완) → 담으로 둘러싸인 건물, 관청
- HSK 등급: 1급

---

### 2. 医生 / Yīshēng / [명사] / 의사

- 한자 풀이:
  - 医: 匚(상자방) + 矢(화살시) → 치료하다
  - 生: 牛(소우) + 一(한일) → 나다, 직업인을 나타내는 접미사
- HSK 등급: 1급

---

### 3. 护士 / Hùshi / [명사] / 간호사

- 한자 풀이:
  - 护: 扌(손수변) + 户(지게호) → 손으로 보호하다
  - 士: 선비의 형상 → 전문직에 종사하는 사람
- HSK 등급: 2급

---

### 4. 病人 / Bìngrén / [명사] / 환자

- 한자 풀이:
  - 病: 疒(병질엄) + 丙(남녁병) → 병, 질병. 丙은 소리 요소
  - 人: 사람의 형상 → 사람
- HSK 등급: 2급

---

### 5. 看病 / Kànbìng / [동사] / 진찰받다, 병을 보다

- 한자 풀이:
  - 看: 手(손수) + 目(눈목) → 손을 눈 위에 얹고 살피다 → 보다, 관찰하다
  - 病: 疒(병질엄) + 丙(남녁병) → 병
- HSK 등급: 2급

---

### 6. 挂号 / Guàhào / [동사] / 접수하다, 번호표를 받다

- 한자 풀이:
  - 挂: 扌(손수변) + 圭(홀규) → 손으로 걸다, 접수하다
  - 号: 口(입구) + 丂(울돼지) → 부르짖다, 번호, 호
- HSK 등급: 4급

---

### 7. 药 / Yào / [명사] / 약

- 한자 풀이:
  - 药: 艹(초두머리) + 约(약속약) → 풀로 만든 약. 约은 소리 요소
- HSK 등급: 1급

---

### 8. 药店 / Yàodiàn / [명사] / 약국

- 한자 풀이:
  - 药: 艹(초두머리) + 约(약속약) → 약
  - 店: 广(엄호) + 占(점령할점) → 가게, 점포
- HSK 등급: 2급

---

### 9. 感冒 / Gǎnmào / [명사/동사] / 감기, 감기에 걸리다

- 한자 풀이:
  - 感: 咸(다함함) + 心(마음심) → 느끼다, 감지하다
  - 冒: 冖(덮을멱) + 目(눈목) → 눈을 덮어쓰다 → 참다, 감기에 걸리다
- HSK 등급: 2급

---

### 10. 发烧 / Fāshāo / [동사] / 열이 나다

- 한자 풀이:
  - 发: 丿(삐침) + 犮(땅이름발) → 나다, 발생하다
  - 烧: 火(불화) + 尧(요임금요) → 태우다, 열이 오르다
- HSK 등급: 2급

---

### 11. 咳嗽 / Késou / [동사] / 기침하다

- 한자 풀이:
  - 咳: 口(입구) + 亥(돼지해) → 기침하다. 亥는 소리 요소
  - 嗽: 口(입구) + 欶(빨삭) → 헛기침하다. 欶는 소리 요소
- HSK 등급: 3급

---

### 12. 头疼 / Tóuténg / [형용사] / 두통, 머리가 아프다

- 한자 풀이:
  - 头: 大(큰대) + 丶(점주) → 머리, 대
  - 疼: 疒(병질엄) + 冬(겨울동) → 아프다, 통증. 冬은 소리 요소
- HSK 등급: 3급

---

### 13. 肚子疼 / Dùzi téng / [형용사] / 복통, 배가 아프다

- 한자 풀이:
  - 肚: 月(육달월) + 土(흙토) → 배. 土는 소리 요소
  - 子: 아기의 형상 → 명사 접미사
  - 疼: 疒(병질엄) + 冬(겨울동) → 아프다
- HSK 등급: 3급

---

### 14. 不舒服 / Bù shūfu / [형용사] / 몸이 좋지 않다, 편찮다

- 한자 풀이:
  - 不: 새가 하늘로 날아오르는 모양 → 부정, ~아니다
  - 舒: 舍(집사) + 予(줄여) → 펴다, 편안하다
  - 服: 月(육달월) + 卩(병부절) + 又(또우) → 옷을 입다, 따르다. 舒服는 "편안하다"
- HSK 등급: 2급

---

### 15. 疼 / Téng / [형용사] / 아프다

- 한자 풀이:
  - 疼: 疒(병질엄) + 冬(겨울동) → 아프다, 통증이 있다
- HSK 등급: 2급

---

### 16. 严重 / Yánzhòng / [형용사] / 심각하다, 중하다

- 한자 풀이:
  - 严: 一(한일) + 亚(버금아) + 丷(여덟팔의 변형) → 엄격하다, 심하다
  - 重: 千(일천천) + 里(마을리) → 무겁다, 중요하다
- HSK 등급: 3급

---

### 17. 检查 / Jiǎnchá / [동사] / 검사하다, 진찰하다

- 한자 풀이:
  - 检: 木(나무목) + 佥(모두첨) → 검사하다, 점검하다
  - 查: 木(나무목) + 旦(아침단) → 조사하다, 살피다
- HSK 등급: 3급

---

### 18. 打针 / Dǎzhēn / [동사] / 주사 맞다

- 한자 풀이:
  - 打: 扌(손수변) + 丁(장정정) → 치다, 행동을 나타냄
  - 针: 钅(쇠금변) + 十(열십) → 바늘, 주사기
- HSK 등급: 3급

---

### 19. 手术 / Shǒushù / [명사] / 수술

- 한자 풀이:
  - 手: 손의 형상 → 손
  - 术: 木(나무목) + 丶(점주) → 기술, 방법
- HSK 등급: 4급

---

### 20. 保险 / Bǎoxiǎn / [명사] / 보험

- 한자 풀이:
  - 保: 亻(사람인변) + 呆(어리석을매) → 사람을 보호하다, 지키다
  - 险: 阝(좌부변) + 佥(모두첨) → 험하다, 위험
- HSK 등급: 4급

---

### 21. 体温 / Tǐwēn / [명사] / 체온

- 한자 풀이:
  - 体: 亻(사람인변) + 本(근본본) → 사람의 몸
  - 温: 氵(삼수변) + 昷(온정온) → 따뜻하다, 온도
- HSK 등급: 3급

---

### 22. 休息 / Xiūxi / [동사] / 쉬다, 휴식하다

- 한자 풀이:
  - 休: 亻(사람인변) + 木(나무목) → 사람이 나무에 기대어 쉬다
  - 息: 自(스스로자) + 心(마음심) → 숨쉬다, 쉬다
- HSK 등급: 1급

---

### 23. 过敏 / Guòmǐn / [형용사/동사] / 알레르기, 과민 반응을 보이다

- 한자 풀이:
  - 过: 辶(책받침) + 寸(마디촌) → 지나가다, 지나치다
  - 敏: 每(매양매) + 攵(칠복) → 민첩하다, 민감하다
- HSK 등급: 4급

---

### 24. 拉肚子 / Lā dùzi / [동사] / 설사하다

- 한자 풀이:
  - 拉: 扌(손수변) + 立(설립) → 잡아당기다. 立은 소리 요소
  - 肚: 月(육달월) + 土(흙토) → 배
  - 子: 아기의 형상 → 명사 접미사
- HSK 등급: 3급

---

### 25. 牙疼 / Yáténg / [형용사] / 치통, 이가 아프다

- 한자 풀이:
  - 牙: 어금니의 형상 → 이, 이빨
  - 疼: 疒(병질엄) + 冬(겨울동) → 아프다
- HSK 등급: 3급

---
