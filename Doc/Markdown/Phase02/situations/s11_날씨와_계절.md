# 날씨와 계절 (天气与季节, Tiānqì yǔ jìjié)

> 상황: 일기예보, 기후, 계절 표현
> 수준: HSK 1~3급 중심
> 단어 수: 25개

---

### 1. 天气 / tiānqì / [명사] / 날씨

- 한자 풀이:
  - 天: 一(한일) + 大(큰대) → 하늘
  - 气: 气(기운기) → 기운, 공기
- HSK 등급: 1급

---

### 2. 晴天 / qíngtiān / [명사] / 맑은 날, 개인 날

- 한자 풀이:
  - 晴: 日(날일) + 青(푸를청) → 개다, 맑다
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 2급

---

### 3. 阴天 / yīntiān / [명사] / 흐린 날

- 한자 풀이:
  - 阴: 阝(좌부변) + 月(달월) → 흐리다, 음
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 3급

---

### 4. 下雨 / xiàyǔ / [동사] / 비가 오다

- 한자 풀이:
  - 下: 一(한일) + 卜(점복) → 아래, 내리다
  - 雨: 雨(비우) → 비
- HSK 등급: 1급

---

### 5. 下雪 / xiàxuě / [동사] / 눈이 오다

- 한자 풀이:
  - 下: 一(한일) + 卜(점복) → 아래, 내리다
  - 雪: 雨(비우) + 彐(돼지머리) → 눈
- HSK 등급: 2급

---

### 6. 刮风 / guāfēng / [동사] / 바람이 불다

- 한자 풀이:
  - 刮: 舌(혀설) + 刂(선칼도방) → 불다, 스치다
  - 风: 几(안석궤) + 乂(벨예) → 바람
- HSK 등급: 2급

---

### 7. 冷 / lěng / [형용사] / 춥다, 차갑다

- 한자 풀이:
  - 冷: 冫(이수변) + 令(하여금령) → 춥다, 차갑다
- HSK 등급: 1급

---

### 8. 热 / rè / [형용사] / 덥다, 뜨겁다

- 한자 풀이:
  - 热: 执(잡을집) + 灬(연화발) → 덥다, 뜨겁다
- HSK 등급: 1급

---

### 9. 暖和 / nuǎnhuo / [형용사] / 따뜻하다

- 한자 풀이:
  - 暖: 日(날일) + 爰(당길원) → 따뜻하다
  - 和: 禾(벼화) + 口(입구) → 온화하다, 화목하다
- HSK 등급: 2급

---

### 10. 凉快 / liángkuai / [형용사] / 시원하다, 선선하다

- 한자 풀이:
  - 凉: 冫(이수변) + 京(서울경) → 서늘하다, 차갑다
  - 快: 忄(심방변) + 夬(터놓을쾌) → 빠르다, 상쾌하다
- HSK 등급: 2급

---

### 11. 春天 / chūntiān / [명사] / 봄

- 한자 풀이:
  - 春: 日(날일) + 三(석삼) + 人(사람인) → 봄
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 1급

---

### 12. 夏天 / xiàtiān / [명사] / 여름

- 한자 풀이:
  - 夏: 一(한일) + 自(스스로자) + 夂(뒤져을치) → 여름
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 1급

---

### 13. 秋天 / qiūtiān / [명사] / 가을

- 한자 풀이:
  - 秋: 禾(벼화) + 火(불화) → 가을
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 1급

---

### 14. 冬天 / dōngtiān / [명사] / 겨울

- 한자 풀이:
  - 冬: 夂(뒤져을치) + 丶(점주) × 2 → 겨울
  - 天: 一(한일) + 大(큰대) → 하늘, 날
- HSK 등급: 1급

---

### 15. 温度 / wēndù / [명사] / 온도

- 한자 풀이:
  - 温: 氵(삼수변) + 昷(온화할온) → 따뜻하다
  - 度: 广(엄호) + 廿(스무입) + 又(또우) → 정도, 법도
- HSK 등급: 2급

---

### 16. 度 / dù / [명사/양사] / 도(온도 단위), 정도

- 한자 풀이:
  - 度: 广(엄호) + 廿(스무입) + 又(또우) → 정도, 도(단위)
- HSK 등급: 2급

---

### 17. 空气 / kōngqì / [명사] / 공기

- 한자 풀이:
  - 空: 穴(구멍혈) + 工(장인공) → 비다, 공중
  - 气: 气(기운기) → 기운, 공기
- HSK 등급: 2급

---

### 18. 雾霾 / wùmái / [명사] / 스모그, 미세먼지

- 한자 풀이:
  - 雾: 雨(비우) + 务(힘쓸무) → 안개
  - 霾: 雨(비우) + 狸(살쾡이리) → 흐리다, 황사
- HSK 등급: 4급

---

### 19. 台风 / táifēng / [명사] / 태풍

- 한자 풀이:
  - 台: 厶(사사사) + 口(입구) → 대, 태
  - 风: 几(안석궤) + 乂(벨예) → 바람
- HSK 등급: 3급

---

### 20. 彩虹 / cǎihóng / [명사] / 무지개

- 한자 풀이:
  - 彩: 采(캘채) + 彡(터럭삼) → 채색, 빛깔
  - 虹: 虫(벌레훼) + 工(장인공) → 무지개

---

### 21. 干燥 / gānzào / [형용사] / 건조하다

- 한자 풀이:
  - 干: 干(방패간) → 마르다, 건조
  - 燥: 火(불화) + 喿(지저귈조) → 마르다, 건조하다
- HSK 등급: 3급

---

### 22. 潮湿 / cháoshī / [형용사] / 습하다, 축축하다

- 한자 풀이:
  - 潮: 氵(삼수변) + 朝(아침조) → 조수, 습기
  - 湿: 氵(삼수변) + 显(나타날현) → 젖다, 습하다

---

### 23. 预报 / yùbào / [명사/동사] / 예보(하다)

- 한자 풀이:
  - 预: 予(나여) + 页(머리혈) → 미리, 예상하다
  - 报: 扌(손수변) + 卩(병부절) → 알리다, 보고하다
- HSK 등급: 3급

---

### 24. 变化 / biànhuà / [명사/동사] / 변화(하다)

- 한자 풀이:
  - 变: 亦(또역) + 又(또우) → 변하다, 바뀌다
  - 化: 亻(사람인변) + 匕(비수비) → 되다, 변화하다
- HSK 등급: 2급

---

### 25. 季节 / jìjié / [명사] / 계절

- 한자 풀이:
  - 季: 禾(벼화) + 子(아들자) → 계절
  - 节: 艹(초두머리) + 卩(병부절) → 마디, 절
- HSK 등급: 2급
