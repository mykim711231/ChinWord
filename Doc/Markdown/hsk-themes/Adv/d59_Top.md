### 5898. 心安理得 / xīn ān lǐ dé / [성어] / 마음이 편안하고 당연하게 여기다

- 한자 풀이:
  - 心: 心(마음 심, 부수) → 마음
  - 安: 宀(집 면) + 女(계집 녀) → 편안하다
  - 理: 王(구슬 옥 변) + 里(마을 리) → 이치
  - 得: 彳(두인변 척) + 㝵(얻을 득) → 얻다
- HSK 등급: 7급
