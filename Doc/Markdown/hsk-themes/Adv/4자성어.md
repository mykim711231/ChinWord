# 4자성어 (四字成语, Sìzì chéngyǔ)

> 주제: 4자 고정 성어, 고전 출전, 문화적 배경
> 수준: HSK 6-9급 중심
> 성어 수: 약 400개 (작성 예정)

---

> ⚠️ **마크다운 포맷 주의**: 이 파일은 다른 d##_Top.md 와 **포맷이 다릅니다**.

## 작성 템플릿

```markdown
### N. 画蛇添足 / huà shé tiān zú / [성어] / 사족, 쓸데없는 일

- 글자별 풀이:
  - 画 (huà): 그리다 → 田(밭전) + 人(사람인) → 그림을 그리다
  - 蛇 (shé): 뱀 → 虫(벌레충) + 它(그것타) → 뱀
  - 添 (tiān): 더하다 → 氵(물수) + 忝(욕될첨) → 보태다
  - 足 (zú): 발 → 足(발족) → 발, 다리
- 원문 / 출전:
  - 《战国策·齐策二》"楚有祠者, 赐其舍人卮酒…"
- 유래:
  - 초나라 어떤 사람이 뱀을 그리는 시합에서, 가장 먼저 그린 사람이
    "나는 뱀의 발도 그릴 수 있다"며 발을 그리다가 다른 사람이 먼저
    완성하여 술을 빼앗긴 고사.
- 현대 용법: 불필요한 일을 더해 오히려 일을 망치는 것을 비유.
- 유의어: 多此一举 (duō cǐ yī jǔ)
- 반의어: 恰到好处 (qià dào hǎo chù)
- HSK 등급: 7-9급

<!-- id: hsk_idiom_0001 -->
```
