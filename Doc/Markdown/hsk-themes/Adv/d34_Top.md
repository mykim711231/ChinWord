  - 气: 구름 기운의 상형 → 기운, 공기
  - 管: 𥫗(대나무 죽) + 官(벼슬 관) → 관, 대롱
- HSK 등급: 7급

### 3399. 利率 / lì lǜ / [명사] / 이자율, 금리

- 한자 풀이:
  - 利: 禾(벼 화) + 刂(칼 도) → 이익
  - 率: 玄(검을 현) + 十(열 십) + 八(여덟 팔) → 비율
- HSK 등급: 7급

### 3400. 看中 / kàn zhòng / [동사] / 마음에 들다

- 한자 풀이:
  - 看: 手(손 수)의 변형 + 目(눈 목) → 보다
  - 中: 丨(뚫을 곤)이 口(입 구)를 관통 → 맞히다, 마음에 들다
- HSK 등급: 7급
