- 한자 풀이:
  - 清: 氵(물 수) + 青(푸를 청) → 맑다, 분명하다
  - 单: 单(홑 단) → 하나, 목록
- HSK 등급: 7급

### 2299. 明智 / míng zhì / [형용사] / 현명하다, 분별 있다

- 한자 풀이:
  - 明: 日(날 일) + 月(달 월) → 밝다
  - 智: 知(알 지) + 日(날 일) → 지혜롭다, 슬기
- HSK 등급: 7급

### 2300. 铅 / qiān / [명사] / 납

- 한자 풀이:
  - 铅: 钅(쇠 금) + 冖(덮을 멱) + 口(입 구) + 几(안석 궤) → 납
- HSK 등급: 7급
