### 5800. 燃放 / rán fàng / [동사] / (폭죽을) 불붙여 쏘다
- 한자 풀이:
  - 燃: 火(불 화) + 然(그럴 연) → 태우다
  - 放: 方(모 방) + 攵(칠 복) → 놓다
- HSK 등급: 7급
