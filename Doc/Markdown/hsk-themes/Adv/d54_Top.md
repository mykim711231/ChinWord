### 5399. 不得而知 / bù dé ér zhī / [성어] / 알 수 없다

- 한자 풀이:

  - 得: 彳(두인 변) + 㝵(얻을 애) → 얻다, 알다
  - 而: 而(말 이을 이) → (접속)
  - 知: 矢(화살 시) + 口(입 구) → 알다
- HSK 등급: 7급
