### 6399. 半边天 / bàn biān tiān / [명사] / 하늘의 반쪽, 여성(의 사회적 역할)

- 한자 풀이:
  - 半: 八(나눌 팔) + 牛(소 우) → 소를 둘로 나누다, 반, 절반
  - 边: 辶(책받침) + 力(힘 력) → 가장자리, 변두리, 쪽
  - 天: 一(한 일) + 大(큰 대) → 사람 위의 하늘, 하늘
- HSK 등급: 7급

### 6400. 足智多谋 / zú zhì duō móu / [성어] / 지혜가 많고 꾀가 많다, 지략이 풍부하다

- 한자 풀이:
  - 足: 발 족, 발의 형상 → 발, 충분하다, 넉넉하다
  - 智: 知(알 지) + 日(날 일) → 날마다 알아 가다, 지혜, 슬기
  - 多: 夕(저녁 석) + 夕(저녁 석) → 저녁이 거듭되다, 많다
  - 谋: 讠(말씀 언) + 某(아무 모) → 말로 꾀를 내다, 꾀, 모략, 계획
- HSK 등급: 7급
