## 구성 원칙

### 1. 빈도 batch 우선 (`d01_Top.md` ~ `dNN_Top.md`)

- **단위:** 100단어/파일
- **정렬:** HSK 공식 빈도 순위 (높은 빈도 → 낮은 빈도)
- **포맷:** Basic tier 와 동일 (단어 / 병음 / 품사 / 뜻 + 한자 풀이 + HSK급 + ID)
- **장점:**
  - 학습자가 "Top 100 먼저" 식으로 우선순위 학습 가능
  - 파일 크기 균일 → 로딩·관리 용이
  - 도메인이 모호한 단어도 빈도 기준으로 자연스럽게 배치

### 2. 4자성어 별도 파일 (`4자성어.md`)

- ⚠️ **다른 파일과 포맷 다름** — 단어 포맷이 아닌 **성어 포맷** 사용:
  - 4글자 각각의 풀이 (字義)
  - 출전·원문 (出處)
  - 유래·고사 (典故)
  - 현대 용법·유의어·반의어
- `idioms/` 폴더와 cross-reference 가능
- 상세 포맷은 `../README.md` §2.2 참고

### 3. 도메인 필터 (메타데이터, 별도 파일 아님)

도메인은 **파일 분리 기준이 아닌 단어별 메타데이터**.
UI 에서 chip 토글로 필터링하며, 한 단어가 여러 도메인에 속할 수 있음.

| 도메인 | 설명 | 예시 |
|---|---|---|
| 정치/외교 | 정치·외교·국제관계 | 主权, 外交, 制裁 |
| 법률/행정 | 법률·행정·제도 | 司法, 立法, 仲裁 |
| 경제/금융 | 거시경제·금융·무역 | 通胀, 股市, 关税 |
| 과학/기술 | 자연과학·공학·IT | 量子, 算法, 基因 |
| 의학/생명 | 의학·생명과학 | 病毒, 免疫, 细胞 |
| 문학/예술 | 문학·예술·미학 | 散文, 流派, 韵律 |
| 역사/철학 | 역사·철학·사상 | 王朝, 思潮, 儒家 |
| 서면어/문어체 | 문어체 전용 register | 此乃, 然则, 谨此 |
| 심리/사회 | 심리학·사회학·교육학 | 焦虑, 阶层, 认知 |
| 4자성어 | 4자 고정 표현 | 画蛇添足 등 |

## 주의 사항

- **HSK 6 (1,123) + 7-9 (5,606)** 합산 분류. UI 에서 chip 으로 `HSK 6` / `HSK 7-9` 토글.
- **서면어/문어체** 는 도메인이 아닌 register (격식체) 이지만, 학습자 입장에서 묶어둘 가치가 큼 (시험 대비 vs 회화 학습 구분).
- **4자성어** 만 별도 파일로 분리한 이유:
  - 포맷 자체가 다름 (글자별 풀이 + 출전 + 유래)
  - 분량이 ~400개로 한 파일에 수용 가능
  - 일반 단어 흐름을 깨지 않기 위함

## 단어 ID 매칭 스크립트

```bash
# HSK 6급 단어 조회
node -e "
const w=require('./app/src/data/hsk-words.json');
const lv=Number(process.argv[1]); // 6 or 7
w.filter(x=>x.hskLevel===lv)
 .forEach(x=>console.log(x.id, x.word, x.pinyin, '|', x.meaningEn?.slice(0,60)));
" 6

# 도메인별 필터링
node -e "
const w=require('./app/src/data/hsk-words.json');
const dom=process.argv[1]; // '정치/외교'
w.filter(x=>x.domains?.includes(dom))
 .forEach(x=>console.log(x.id, x.word, x.pinyin));
" '정치/외교'
```
