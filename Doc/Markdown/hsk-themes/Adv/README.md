## 주의

- HSK 6 (1,123) 과 7-9 (5,606) 은 합산 분류 가능 (UI 가 chip 으로 6/7-9 토글).
- **4자성어 (`d09_4자성어.md`)** 는 별도 도메인으로 처리해 기존 `idioms/` 와
  cross-reference 가능. **마크다운 포맷은 단어 포맷이 아니라 성어 포맷**(글자별 풀이,
  원문, 유래, 유의어)을 사용한다. 상세는 `../README.md` §2.2 참고.
- **서면어/문어체** 는 도메인이 아니라 register 이지만, 학습자 입장에서 묶어둘
  가치 큼 (시험 대비 vs 회화 학습 구분). 단어 포맷 사용.

## 단어 ID 매칭

```bash
node -e "
const w=require('./app/src/data/hsk-words.json');
const lv=Number(process.argv[1]); // 6 or 7
w.filter(x=>x.hskLevel===lv).forEach(x=>console.log(x.id, x.word, x.pinyin, '|', x.meaningEn?.slice(0,60)));
" 6
```
