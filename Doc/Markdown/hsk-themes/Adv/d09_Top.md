### 898. 山坡 / shān pō / [명사] / 산비탈, 산기슭

- 한자 풀이:
  - 山: 산봉우리의 상형 → 산
  - 坡: 土(흙 토) + 皮(가죽 피) → 비탈
- HSK 등급: 6급

### 899. 增进 / zēng jìn / [동사] / 증진하다, 향상시키다

- 한자 풀이:
  - 增: 土(흙 토) + 曾(일찍 증) → 더하다, 증가하다
  - 进: 辶(쉬엄쉬엄 갈 착) + 井(우물 정) → 나아가다
- HSK 등급: 6급

### 900. 只顾 / zhǐ gù / [부사] / 오로지 ~에만 신경 쓰다

- 한자 풀이:
  - 只: 口(입 구) + 八(여덟 팔) → 다만, 오직
  - 顾: 厄(재앙 액) + 页(머리 혈) → 돌보다, 신경 쓰다
- HSK 등급: 6급
