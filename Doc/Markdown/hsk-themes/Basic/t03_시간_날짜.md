> 상황: 시간·시각 표현, 날짜·요일·달, 계절
> 수준: HSK 1~3급 중심
> 단어 수: 60개

---

### 1. 时间 / shíjiān / [명사] / 시간, 시각

- 한자 풀이:
  - 时: 日(날 일) + 寸(마디 촌) → 때, 시간 (時의 간략형)
  - 间: 门(문 문) + 日(날 일) → 사이, 간격 (間의 간략형)
- HSK 등급: 2급

  - 将: 丬(장수 장 변, 爿의 간략형) + 月(육달 월) + 寸(마디 촌) → 장차, 미래 (將의 간략형)
  - 来(올 래) → 來의 간략형 → 오다, 미래
- HSK 등급: 2급

### 57. 过去 / guò qu / [명사/동사] / 과거, 지나다

- 한자 풀이:
  - 过: 辶(쉬엄쉬엄 갈 착) + 寸(마디 촌) → 지나다 (過의 간략형)
  - 去: 土(흙 토) + 厶(사사) → 가다, 떠나다
- HSK 등급: 1급

### 58. 最近 / zuì jìn / [명사/부사] / 최근, 요즘, 가깝다

- 한자 풀이:
  - 最: 日(날 일) + 取(취할 취) → 가장, 최고
  - 近: 辶(쉬엄쉬엄 갈 착) + 斤(근 근) → 가깝다, 최근
- HSK 등급: 1급
