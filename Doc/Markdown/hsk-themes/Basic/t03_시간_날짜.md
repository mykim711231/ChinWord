# 시간과 날짜 (时间与日期, Shíjiān yǔ rìqī)

> 상황: 시간·시각 표현, 날짜·요일·달, 계절
> 수준: HSK 1~3급 중심
> 단어 수: 60개

---

### 1. 时间 / shíjiān / [명사] / 시간, 시각

- 한자 풀이:
  - 时: 日(날일) + 寺(절사) → 때, 시간
  - 间: 门(문문) + 日(날일) → 사이, 간격
- HSK 등급: 2급

### 58. 最近 / zuì jìn / [명사/부사] / 최근, 요즘, 가깝다

- 한자 풀이:
  - 最: 月(달월) + 罒(그물망) → 가장, 최고
  - 近: 辶(걷기변) + 斤(근근) → 가깝다, 최근 (가까운 시간)
- HSK 등급: 1급
