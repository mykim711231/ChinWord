# 날씨와 자연 (天气与自然, Tiānqì yǔ zìrán)

> 상황: 날씨 현상, 계절, 자연·동식물 관찰, 기후 표현
> 수준: HSK 2~4급 중심
> 단어 수: 15개

---

### 1. 天气 / tiān qì / [명사] / 날씨, 기후

- 한자 풀이:
  - 天: 一(한일) + 大(큰대) → 하늘, 날씨
  - 气: 气(기운기) → 기운, 날씨
- HSK 등급: 1급
