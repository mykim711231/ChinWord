# 4자성어 (四字成語) - 1~50

> 순위: 1-50번
> 수준: 광범위 학습 (200개 중)
> 성어 수: 50개

---

### 1. 温故知新 / Wēn gù zhī xīn / [성어] / 옛것을 익히고 새것을 안다

- 원문: 温故知新 (Wēn gù zhī xīn) — 『논어』 위정편
- 유래: 공자의 말에서 유래. 배운 것을 복습하고 새로운 의미를 발견하는 태도를 강조.
- 글자별 풀이:
  - 温 (wēn): 따뜻할 온 — 데우다, 복습하다
  - 故 (gù): 옛 고 — 지나간 일, 이미 배운 것
  - 知 (zhī): 알 지 — 깨닫다, 이해하다
  - 新 (xīn): 새 신 — 새로운 것, 혁신
- 유의어:
  - 学而时习 (xué ér shí xí): 배우고 때때로 익히다
  - 鉴往知来 (jiàn wǎng zhī lái): 과거를 거울삼아 미래를 알다

### 2. 卧虎藏龙 / Wò hǔ cáng lóng / [성어] / 숨겨진 인재가 많다

- 원문: 卧虎藏龙 (Wò hǔ cáng lóng) — 중국 고대 민간 이야기
- 유래: 표면에는 드러나지 않지만 뛰어난 인재나 능력이 감춰져 있음을 의미.
- 글자별 풀이:
  - 卧 (wò): 누울 와 — 숨어있다, 웅크리다
  - 虎 (hǔ): 호랑이 호 — 맹수, 강함
  - 藏 (cáng): 숨길 장 — 감춘다, 은폐하다
  - 龙 (lóng): 용 용 — 비의상징, 최고의 것
- 유의어:
  - 藏龙卧虎 (cáng lóng wò hǔ): 용과 호랑이가 숨어있다
  - 人杰地灵 (rén jié dì líng): 사람이 뛰어나고 땅이 영험하다

- 원문: 画龙点睛 (Huà lóng diǎn jīng) — 『진서』 안도편
- 유래: 용을 그릴 때 눈을 그려 넣음으로써 완성된다는 뜻.
- 글자별 풀이:
  - 画 (huà): 그릴 화 — 그리다, 도형
  - 龙 (lóng): 용 용 — 비의상징, 최고의 것
  - 点 (diǎn): 찍을 점 — 찍다, 표시
  - 睛 (jīng): 눈동자 정 — 눈, 명확함
- 유의어:
  - 锦上添花 (jǐn shàng tiān huā): 비단 위에 꽃을 더하다
  - 妙笔生花 (miào bǐ shēng huā): 묘한 붓으로 꽃을 피우다

### 4. 龙飞凤舞 / Lóng fēi fèng wǔ / [성어] / 기세있고 우아하다

- 원문: 龙飞凤舞 (Lóng fēi fèng wǔ) — 중국 고대 성어
- 유래: 용이 날고 봉황이 춘다는 뜻으로 기세있고 우아한 모습을 표현.
- 글자별 풀이:
  - 龙 (lóng): 용 용 — 최고의 것, 강력함

  - 凤 (fèng): 봉황 봉 — 상서로운 새, 귀함
  - 舞 (wǔ): 춤 무 — 춤을 춘다, 움직인다
- 유의어:
  - 笔走龙蛇 (bǐ zǒu lóng shé): 붓이 용과 뱀처럼 움직인다
  - 生龙活虎 (shēng lóng huó hǔ): 생동하는 용과 호랑이

- 유의어:

  - 虎头鼠尾 (hǔ tóu shǔ wěi): 호랑이 머리에 쥐 꼬리

### 10. 为虎添翼 / Wéi hǔ tiān yì / [성어] / 악을 도와주다

  - 为 (wéi): 할 위 — 돕다, 만들다, 행동
  - 虎 (hǔ): 호랑이 호 — 악, 재앙
  - 添 (tiān): 더할 첨 — 더하다, 증가시키다
  - 翼 (yì): 날개 익 — 날개, 힘, 도움
- 유의어:
  - 如虎添翼 (rú hǔ tiān yì): 호랑이가 날개를 얻다
  - 助纣为虐 (zhù zhòu wéi nüè): 악을 돕다, 폭군을 돕다
