# 4자성어 (四字成語) - 101~150

> 순위: 101-150번
> 수준: 광범위 학습 (200개 중)
> 성어 수: 50개

---

### 101. 何乐而不为 / Hé lè ér bùwéi / [성어] / 무엇이 즐거워서 하지 않는가

- 의미: 무엇이 즐거워서 하지 않겠는가. 이익이 되고 즐거운 일인데 마다할 이유가 없다는 뜻으로, 좋은 기회나 당연히 해야 할 일을 적극적으로 수용하는 태도를 나타낸다.
- 글자별 풀이:
  - 何 (hé): 무엇 하 — 무엇, 어떤
  - 乐 (lè): 즐길 락 — 즐기다, 기뻐하다
  - 而 (ér): 말 이 — 그러면서, 그리고
  - 不 (bù): 아닐 불 — 아니다, 부정
  - 为 (wéi): 할 위 — 하다, 행동하다
- 유의어:
  - 何乐不为 (hé lè bùwéi): 기쁘면 왜 하지 않겠는가
  - 愿意之至 (yuàn yì zhī zhì): 기꺼이 함

### 102. 何患无辞 / Hé huàn wú cí / [성어] / 무엇이 말이 없음을 근심하는가

- 의미: 무엇이 말이 없음을 걱정하랴. 핑계나 구실을 찾는 것은 얼마든지 가능하다는 뜻으로, 억지를 부리려면 얼마든지 이유를 댈 수 있음을 비유한다.
- 글자별 풀이:
  - 何 (hé): 무엇 하 — 무엇, 어떻게
  - 患 (huàn): 걱정 환 — 걱정하다, 근심하다
  - 无 (wú): 없을 무 — 없다, 무
  - 辞 (cí): 말 사 — 말, 사유
- 유의어:
  - 言之有理 (yán zhī yǒu lǐ): 말이 도리가 있다
  - 借口百般 (jiè kǒu bǎi bān): 핑계가 백가지다

### 103. 何去何从 / Hé qù hé cóng / [성어] / 어디로 갈 것이며 어디를 따를 것인가

- 의미: 어디로 가고 어디를 따라야 하는가. 어려운 선택의 갈림길에서 방향을 정하지 못하고 고민하는 상황을 나타낸다.
- 글자별 풀이:
  - 何 (hé): 무엇 하 — 무엇, 어디
  - 去 (qù): 갈 거 — 가다, 떠나다
  - 何 (hé): 무엇 하 — 무엇, 어디
  - 从 (cóng): 따를 종 — 따르다, 따라가다
- 유의어:
  - 左右为难 (zuǒ yòu wéi nán): 좌우로 어려움을 당한다
  - 抉择困难 (jué zé kùn nan): 선택이 어렵다

### 104. 合盘托出 / Hé pán tuō chū / [성어] / 합쳐진 그릇을 내어준다

- 의미: 쟁반째로 들어내다. 숨김없이 모든 사실이나 생각을 다 털어놓는 것을 비유한다. 주로 솔직하고 진실된 태도를 강조할 때 사용된다.
- 글자별 풀이:
  - 合 (hé): 합할 합 — 함께하다, 모으다
  - 盘 (pán): 쟁반 반 — 쟁반, 담다
  - 托 (tuō): 맡길 탁 — 맡기다, 든다
  - 出 (chū): 나갈 출 — 나가다, 드러나다
- 유의어:
  - 掏心掏肺 (tāo xīn tāo fèi): 심장과 폐를 꺼낸다 (진심으로 대하다)
  - 肝胆相照 (gān dǎn xiāng zhào): 간담이 서로 비친다

### 105. 合家欢乐 / Hé jiā huān lè / [성어] / 가족이 함께 즐거움

- 의미: 온 가족이 함께 즐겁고 행복하다. 가족 모두가 화목하고 즐거운 분위기를 나타내는 축복의 인사말로, 명절이나 새해 인사에 자주 쓰인다.
- 글자별 풀이:
  - 合 (hé): 합할 합 — 함께, 모으다
  - 家 (jiā): 집 가 — 가족, 집
  - 欢 (huān): 즐길 환 — 기쁘다, 즐기다
  - 乐 (lè): 즐길 락 — 행복하다, 즐거워하다
- 유의어:
  - 天伦之乐 (tiān lún zhī lè): 천성적인 사람관계의 즐거움
  - 其乐融融 (qī lè róng róng): 즐거움이 녹아난다

### 106. 号召力强 / Hào zhào lì qiáng / [성어] / 호소력이 강함

- 의미: 호소력과 영향력이 강하다. 사람들을 불러 모으고 이끄는 능력이 뛰어나다는 뜻으로, 리더십이나 카리스마를 가리킨다.
- 글자별 풀이:
  - 号 (hào): 이름 호 — 호출하다, 소리내다
  - 召 (zhào): 부를 소 — 부르다, 소환하다
  - 力 (lì): 힘 력 — 힘, 능력
  - 强 (qiáng): 셀 강 — 강하다, 강력하다
- 유의어:
  - 魅力无穷 (mèi lì wú qióng): 매력이 무궁하다
  - 引人入胜 (yǐn rén rù shèng): 사람을 우수한 경지로 이끈다

### 107. 好高骛远 / Hào gāo wù yuǎn / [성어] / 높은 것을 좋아하고 먼 것을 추구

- 의미: 높은 것만 좋아하고 먼 것만 추구하다. 자신의 분수나 현실을 무시하고 지나치게 높은 목표만 좇는 태도를 비판적으로 이르는 말이다.
- 글자별 풀이:
  - 好 (hào): 좋아할 호 — 좋아하다, 즐기다
  - 高 (gāo): 높을 고 — 높다, 높은 것
  - 骛 (wù): 달릴 무 — 추구하다, 달리다
  - 远 (yuǎn): 멀 원 — 멀다, 먼 것
- 유의어:
  - 妄想不切实际 (wàng xiǎng bù qiē shí jì): 공상이 현실적이지 않다
  - 志大才疏 (zhì dà cái shū): 뜻은 크나 재능이 부족하다

### 108. 好事不出门 / Hǎo shì bùchū mén / [성어] / 좋은 일은 문 밖으로 나가지 않는다

- 의미: 좋은 일은 문밖으로 나가지 않는다. 좋은 소문은 쉽게 퍼지지 않는 반면, 나쁜 소문은 빠르게 널리 퍼짐을 비유하는 속담이다.
- 글자별 풀이:
  - 好 (hǎo): 좋을 호 — 좋다, 착하다
  - 事 (shì): 일 사 — 일, 사건
  - 不 (bù): 아닐 불 — 아니다, 부정
  - 出 (chū): 나갈 출 — 나가다, 드러나다
  - 门 (mén): 문 문 — 문, 밖
- 유의어:
  - 坏事传千里 (huài shì chuán qiān lǐ): 나쁜 일은 천리를 전한다
  - 恶名远扬 (è míng yuǎn yáng): 나쁜 이름이 멀리 퍼진다

---

### 109. 好言相劝 / Hǎo yán xiāng quàn / [성어] / 좋은 말로 서로 권함

- 의미: 좋은 말로 서로 권하다. 상대방의 이익을 위해 부드럽고 친절한 말로 타일러 권하는 것을 뜻한다.
- 글자별 풀이:
  - 好 (hǎo): 좋을 호 — 좋다, 친절하다
  - 言 (yán): 말 언 — 말, 언어
  - 相 (xiāng): 서로 상 — 서로, 함께
  - 劝 (quàn): 권할 권 — 권하다, 설득하다
- 유의어:
  - 言辞恳切 (yán cí kěn qiè): 말씨가 간절하다
  - 循循善诱 (xún xún shàn yòu): 차례로 착하게 유도하다

### 110. 好逸恶劳 / Hào yì wù láo / [성어] / 편함을 좋아하고 일을 싫어함

- 의미: 편안함을 좋아하고 일하기를 싫어하다. 게으름을 피우며 힘든 일은 피하고 즐거운 일만 찾는 태도를 비판하는 말이다.
- 글자별 풀이:
  - 好 (hào): 좋아할 호 — 좋아하다, 즐기다
  - 逸 (yì): 편할 일 — 편하다, 여유로운
  - 恶 (wù): 싫어할 오 — 싫어하다, 미워하다
  - 劳 (láo): 일 로 — 일, 수고
- 유의어:
  - 游手好闲 (yóu shǒu hào xián): 손으로 놀며 한가로움을 좋아한다
  - 懒惰成性 (lǎn duò chéng xìng): 게으름이 천성이 되다

### 111. 浩气长存 / Hào qì cháng cún / [성어] / 큰 기운이 길게 존재함

- 의미: 큰 정기가 영원히 남다. 강한 정의감과 곧은 기개가 사라지지 않고 오래오래 지속됨을 나타낸다. 주로 충의와 절개를 기리는 맥락에서 사용된다.
- 글자별 풀이:
  - 浩 (hào): 클 호 — 크다, 광대하다
  - 气 (qì): 기운 기 — 기운, 정신
  - 长 (cháng): 길 장 — 길다, 오래
  - 存 (cún): 있을 존 — 있다, 남다
- 유의어:
  - 正气凛然 (zhèng qì lǐn rán): 정기가 엄숙하다
  - 大义凛然 (dà yì lǐn rán): 대의가 엄숙하다

### 112. 浩然之气 / Hào rán zhī qì / [성어] / 큰 정당성의 기운

- 의미: 호연지기. 크고 넓은 정당한 마음의 기운을 뜻한다. 맹자가 말한 도덕적 용기와 정의감으로, 어떤 부당함에도 굴하지 않는 당당한 정신 상태를 가리킨다.
- 글자별 풀이:
  - 浩 (hào): 클 호 — 크다, 광대하다
  - 然 (rán): 그러할 연 — 그렇다, 이와 같다
  - 之 (zhī): 갈 지 — 의, ~의
  - 气 (qì): 기운 기 — 기운, 정신
- 유의어:
  - 正义感十足 (zhèng yì gǎn shí zú): 정의감이 충분하다
  - 光明磊落 (guāng míng lěi luò): 밝고 떳떳하다

---

### 113. 禾下乘凉 / Hé xià chéng liáng / [성어] / 벼 아래서 서늘함을 탄다

- 의미: 벼 아래서 서늘함을 즐기다. 현실에서는 불가능한 일을 꿈꾸는 것을 비유한다. 벼 아래서 그늘을 즐긴다는 것은 아직 자라지 않은 농작물 아래에서 쉬려는 어리석은 발상에서 비롯되었다.
- 글자별 풀이:
  - 禾 (hé): 벼 화 — 벼, 곡식
  - 下 (xià): 아래 하 — 아래, 밑
  - 乘 (chéng): 탈 승 — 타다, 이용하다
  - 凉 (liáng): 서늘 량 — 시원하다, 서늘하다
- 유의어:
  - 痴心妄想 (chī xīn wàng xiǎng): 어리석은 마음으로 공상한다
  - 异想天开 (yì xiǎng tiān kāi): 기이한 생각을 하늘처럼 드높인다

### 114. 和为贵 / Hé wéi guì / [성어] / 조화를 귀히 여긴다

- 의미: 화합을 가장 귀하게 여긴다. 공자(孔子)가 강조한 덕목으로, 사람 사이의 조화와 평화가 무엇보다 소중함을 나타내는 말이다.
- 글자별 풀이:
  - 和 (hé): 화할 화 — 조화, 평화
  - 为 (wéi): 할 위 — 하다, 여기다
  - 贵 (guì): 귀할 귀 — 귀하다, 소중하다
- 유의어:
  - 万事和为贵 (wàn shì hé wéi guì): 모든 일에 조화를 귀히 여긴다
  - 讲究和气 (jiǎng jiù hé qì): 화기를 강조하다

### 115. 和衣而卧 / Hé yī ér wò / [성어] / 옷을 입은 채 누운다

- 의미: 옷을 입은 채로 눕다. 벗지 않고 옷을 입은 상태에서 바로 눕거나 잠드는 것을 말하며, 주로 몹시 피곤하거나 급한 상황을 나타낸다.
- 글자별 풀이:
  - 和 (hé): 함께 화 — 함께, 더하다
  - 衣 (yī): 옷 의 — 옷, 입다
  - 而 (ér): 말 이 — 그러면서, 그리고
  - 卧 (wò): 누울 와 — 누우다, 누워있다
- 유의어:
  - 衣不解带 (yī bù jiě dài): 옷 끈을 풀지 않다
  - 急睡 (jí shuì): 급하게 자다

### 116. 和气生财 / Hé qì shēng cái / [성어] / 화기에서 재물이 생긴다

- 의미: 온화한 기운이 재물을 낳는다. 사람 사이의 화목한 분위기가 결국 부와 번영을 가져온다는 뜻으로, 중국 상인들이 즐겨 쓰는 경영 철학이기도 하다.
- 글자별 풀이:
  - 和 (hé): 화할 화 — 조화, 평화
  - 气 (qì): 기운 기 — 기운, 분위기
  - 生 (shēng): 날 생 — 나다, 생기다
  - 财 (cái): 재물 재 — 재산, 부자
- 유의어:
  - 团结就是力量 (tuán jié jiùshi lì liàng): 단결이 곧 힘이다
  - 和睦生利 (hé mù shēng lì): 화목이 이익을 낳는다

### 117. 和睦相处 / Hé mù xiāng chǔ / [성어] / 화목하게 서로 처한다

- 의미: 화목하게 서로 어울려 지내다. 다툼 없이 사이좋게 지내는 것을 뜻하며, 가족, 이웃, 동료 사이의 원만한 관계를 나타낸다.
- 글자별 풀이:
  - 和 (hé): 화할 화 — 조화, 평화
  - 睦 (mù): 화목할 목 — 친하다, 화목하다
  - 相 (xiāng): 서로 상 — 서로, 함께
  - 处 (chǔ): 처할 처 — 다루다, 지내다
- 유의어:
  - 亲如一人 (qīn rú yī rén): 가까움이 한 사람과 같다
  - 相安无事 (xiāng ān wú shì): 서로 편안하고 사건이 없다

---

### 118. 核心竞争力 / Hé xīn jìng zhēng lì / [성어] / 핵심 경쟁력

- 의미: 핵심적인 경쟁 우위를 차지하는 능력. 기업이나 조직이 다른 경쟁자보다 뛰어난 성과를 내는 근본적인 역량을 가리키는 현대 경영 용어이다.
- 글자별 풀이:
  - 核 (hé): 씨 핵 — 중심, 핵심
  - 心 (xīn): 마음 심 — 중심, 마음
  - 竞 (jìng): 다툴 경 — 경쟁하다, 겨루다
  - 争力 (zhēng lì): 다투다 쟁, 힘 력 — 경합, 능력
- 유의어:
  - 优势竞争 (yōu shì jìng zhēng): 우위 경쟁
  - 比较优势 (bǐ jiào yōu shì): 상대적 우위

### 119. 黑白分明 / Hēi bái fēn míng / [성어] / 검은 것과 흰 것이 분명하다

- 의미: 검은 것과 흰 것이 뚜렷이 구분되다. 옳고 그름이나 선과 악의 경계가 명확하여 혼동의 여지가 없음을 나타낸다.
- 글자별 풀이:
  - 黑 (hēi): 검을 흑 — 검다, 어두운
  - 白 (bái): 흰 백 — 희다, 밝은
  - 分 (fēn): 나눌 분 — 나누다, 구분하다
  - 明 (míng): 밝을 명 — 밝다, 분명하다
- 유의어:
  - 是非分明 (shì fēi fēn míng): 옳고 그름이 분명하다
  - 对错明确 (duì cuò míng què): 맞고 틀림이 명확하다

### 120. 黑云压城 / Hēi yún yā chéng / [성어] / 검은 구름이 성을 누른다

- 의미: 검은 구름이 성을 누르다. 위기나 재앙이 눈앞에 닥쳐와 긴장감이 감도는 상황을 비유한다. 원래는 적군이 몰려와 성을 압박하는 전쟁의 긴박함을 묘사한 데서 유래했다.
- 글자별 풀이:
  - 黑 (hēi): 검을 흑 — 검다, 어두운
  - 云 (yún): 구름 운 — 구름, 흐리다
  - 压 (yā): 누를 압 — 누르다, 억압하다
  - 城 (chéng): 성 성 — 성, 도시
- 유의어:
  - 乌云密布 (wū yún mì bù): 까마귀 구름이 빽빽이 드리워있다
