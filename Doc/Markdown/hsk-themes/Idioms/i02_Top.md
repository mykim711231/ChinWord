# 4자성어 (四字成語) - 51~100

> 순위: 51-100번
> 수준: 광범위 학습 (200개 중)
> 성어 수: 50개

### 51. 入木三分 / Rù mù sān fēn / [성어] / 나무에 세 치 들어간다

- 의미: 붓글씨의 힘이 나무판에 세 푼 깊이까지 스며들 정도로 필력이 강하고 깊다는 뜻. 분석이나 묘사가 매우 날카롭고 깊이 있음을 비유한다.
- 글자별 풀이:
  - 入 (rù): 들 입 — 들어가다, 진입하다
  - 木 (mù): 나무 목 — 나무, 목재
  - 三 (sān): 셋 삼 — 셋, 세 개
  - 分 (fēn): 나눌 분 — 나누다, 분
- 유의어:
  - 力透纸背 (lì tòu zhǐ bèi): 힘이 종이를 뚫고 나간다
  - 铁画银钩 (tiě huà yín gōu): 철 그림, 은 갈고리 (글씨가 강하고 우아하다)

### 52. 入镜可餐 / Rù jìng kě cān / [성어] / 거울에 비친 것을 먹을 수 있다

- 의미: 거울에 비친 모습을 바라보며 식욕이 생길 정도로 외모가 아름다움을 이르는 말. 주로 여성의 뛰어난 미모를 찬양할 때 사용한다.
- 글자별 풀이:
  - 入 (rù): 들 입 — 들어가다, 진입하다
  - 镜 (jìng): 거울 경 — 거울
  - 可 (kě): 옳을 가 — 옳다, 가능하다
  - 餐 (cān): 밥 찬 — 음식, 식사하다
- 유의어:
  - 姿容绝代 (zī róng jué dài): 자태가 세상에 비할 수 없다
  - 倾城倾国 (qīng chéng qīng guó): 나라를 넘어뜨리는 미인

### 53. 八面玲珑 / Bā miàn líng lóng / [성어] / 여덟 방면이 또렷하고 반짝인다

- 의미: 모든 면에서 막힘이 없고 매끄럽다. 사람이 매우 영리하고 처세에 능하여 어느 상황에서도 잘 대처함을 이른다.
- 글자별 풀이:
  - 八 (bā): 여덟 팔 — 여덟
  - 面 (miàn): 면 면 — 면, 방면
  - 玲 (líng): 옥 소리 령 — 맑고 아름답다
  - 珑 (lóng): 옥 소리 롱 — 맑고 아름답다
- 유의어:
  - 面面俱到 (miàn miàn jù dào): 모든 방면을 다 도달한다
  - 十全十美 (shí quán shí měi): 열 개 모두 완벽하다

### 54. 八仙过海 / Bā xiān guò hǎi / [성어] / 팔 신선이 바다를 건넌다

- 의미: 여덟 신선이 각자 자신의 능력을 발휘하여 바다를 건넌다는 뜻으로, 각자 저마다의 재주와 방법으로 일을 해결함을 비유한다.
- 글자별 풀이:
  - 八 (bā): 여덟 팔 — 여덟
  - 仙 (xiān): 신선 선 — 신선, 도사
  - 过 (guò): 지날 과 — 지나다, 건너다
  - 海 (hǎi): 바다 해 — 바다, 대양
- 유의어:
  - 各显神通 (gè xiǎn shén tōng): 각각 신통한 능력을 드러내다
  - 八仙各显其能 (bā xiān gè xiǎn qī néng): 팔 신선이 각각 능력을 드러내다

### 55. 九牛一毛 / Jiǔ niú yī máo / [성어] / 아홉 소 한 터럭

- 의미: 아홉 마리 소의 털 가운데 하나라는 뜻으로, 아주 많은 것 가운데 극히 작은 일부에 불과함을 비유한다.
- 글자별 풀이:
  - 九 (jiǔ): 아홉 구 — 아홉
  - 牛 (niú): 소 우 — 소, 황소
  - 一 (yī): 하나 일 — 한, 하나
  - 毛 (máo): 터럭 모 — 털, 터럭
- 유의어:
  - 沧海一粟 (cāng hǎi yī sù): 창하의 한 알의 좁쌀
  - 冰山一角 (bīng shān yī jiǎo): 빙산의 한 모서리

### 56. 九死一生 / Jiǔ sǐ yī shēng / [성어] / 아홉 번 죽고 한 번 산다

- 의미: 아홉 번 죽을 고비를 넘기고 겨우 한 번 살아난다는 뜻으로, 여러 차례 위험을 겪고 간신히 목숨을 건짐을 이른다.
- 글자별 풀이:
  - 九 (jiǔ): 아홉 구 — 아홉
  - 死 (sǐ): 죽을 사 — 죽다, 사망하다
  - 一 (yī): 하나 일 — 한, 하나
  - 生 (shēng): 날 생 — 살다, 생명
- 유의어:
  - 九死还魂 (jiǔ sǐ huán hún): 아홉 번 죽었다가 혼이 돌아온다
  - 险象环生 (xiǎn xiàng huán shēng): 위험한 형상이 연속적으로 나타난다

### 57. 九霄云外 / Jiǔ xiāo yún wài / [성어] / 구름 밖의 아홉 하늘

- 의미: 구름 밖의 아홉 번째 하늘, 즉 가장 높고 먼 곳을 이르는 말. 어떤 것을 완전히 잊거나 생각 밖으로 밀어낸 상황을 비유한다.
- 글자별 풀이:
  - 九 (jiǔ): 아홉 구 — 아홉
  - 霄 (xiāo): 하늘 소 — 하늘, 대기
  - 云 (yún): 구름 운 — 구름
  - 外 (wài): 밖 외 — 밖, 바깥
- 유의어:
  - 远在天边 (yuǎn zài tiān biān): 하늘의 끝까지 멀다
  - 遥不可及 (yáo bù kě jí): 아득하게 닿을 수 없다

### 58. 五光十色 / Wǔ guāng shí sè / [성어] / 다섯 가지 빛 열 가지 색

- 의미: 여러 가지 빛과 색깔이 어우러져 찬란하고 화려한 모양. 색깔이 다양하거나 사물이 다채로움을 형용한다.
- 글자별 풀이:
  - 五 (wǔ): 다섯 오 — 다섯
  - 光 (guāng): 빛 광 — 빛, 광채
  - 十 (shí): 열 십 — 열, 십
  - 色 (sè): 색 색 — 색깔, 색채
- 유의어:
  - 璀璨夺目 (cuǐ càn duó mù): 눈부시게 빛난다
  - 绚丽多彩 (xuàn lì duō cǎi): 화려하고 다양한 색채

### 59. 五体投地 / Wǔ tǐ tóu dì / [성어] / 다섯 신체를 땅에 던진다

- 의미: 두 팔, 두 무릎, 이마를 땅에 대고 절하는 최고의 경례 동작에서 유래하여, 상대에게 전적으로 감복하거나 존경함을 이르는 말.
- 글자별 풀이:
  - 五 (wǔ): 다섯 오 — 다섯
  - 体 (tǐ): 몸 체 — 몸, 신체
  - 投 (tóu): 던질 투 — 던지다, 내던지다
  - 地 (dì): 땅 지 — 땅, 바닥
- 유의어:
  - 叹为观止 (tàn wéi guān zhǐ): 아! 하고 감탄하며 바라본다
  - 佩服得五体投地 (pèi fú de wǔ tǐ tóu dì): 오체투지할 정도로 존경한다

### 60. 五谷丰登 / Wǔ gǔ fēng dēng / [성어] / 다섯 곡식이 풍성하게 내린다

- 의미: 다섯 가지 곡식이 잘 자라고 풍성하게 수확된다는 뜻으로, 농사가 잘되어 풍년이 듦을 의미하는 길상의 말.
- 글자별 풀이:
  - 五 (wǔ): 다섯 오 — 다섯
  - 谷 (gǔ): 곡식 곡 — 곡식, 곡물
  - 丰 (fēng): 풍성할 풍 — 풍성하다, 많다
  - 登 (dēng): 오를 등 — 내리다, 올라가다
- 유의어:
  - 年年丰收 (nián nián fēng shōu): 해마다 풍성한 수확
  - 万物生长 (wàn wù shēng zhǎng): 만물이 자란다

### 61. 四面楚歌 / Sì miàn chǔ gē / [성어] / 사면에서 초나라 노래가 들린다

- 의미: 사방에서 초나라의 노랫소리가 들린다는 뜻으로, 적에게 완전히 포위되어 고립무원의 상태에 빠짐을 비유. 항우가 해하之战에서 패망한 고사에서 유래.
- 글자별 풀이:
  - 四 (sì): 사 사 — 사, 네 개
  - 面 (miàn): 면 면 — 면, 방면
  - 楚 (chǔ): 초나라 초 — 초나라
  - 歌 (gē): 노래 가 — 노래, 부르다
- 유의어:
  - 孤立无援 (gū lì wú yuán): 외로이 고립되어 도움이 없다
  - 走投无路 (zǒu tóu wú lù): 도망칠 길이 없다

---

### 62. 四通八达 / Sì tōng bā dá / [성어] / 사방으로 통하고 여덟 방향

- 의미: 사방팔방으로 길이 모두 통하여 교통이 편리하고 왕래가 자유로움. 도로망이나 통신망이 잘 발달되어 막힘이 없음을 가리킨다.
- 글자별 풀이:
  - 四 (sì): 사 사 — 사, 네 개
  - 通 (tōng): 통할 통 — 통하다, 연결되다
  - 八 (bā): 여덟 팔 — 여덟
  - 达 (dá): 도달할 달 — 도달하다, 이르다
- 유의어:
  - 交通便利 (jiāo tōng biàn lì): 교통이 편리하다
  - 四通八达 (sì tōng bā dá): 사방으로 모두 통한다

### 63. 四季如春 / Sì jì rú chūn / [성어] / 사계절이 봄 같다

- 의미: 일 년 사계절이 항상 봄처럼 따뜻하고 화창함. 주로 온화한 기후나 쾌적한 환경을 묘사할 때 사용한다.
- 글자별 풀이:
  - 四 (sì): 사 사 — 사, 네 개
  - 季 (jì): 계절 계 — 계절, 철
  - 如 (rú): 같을 여 — 같다, ~처럼
  - 春 (chūn): 봄 춘 — 봄
- 유의어:
  - 春暖花开 (chūn nuǎn huā kāi): 봄이 따뜻하고 꽃이 핀다
  - 温暖如春 (wēn nuǎn rú chūn): 따뜻함이 봄 같다

### 64. 六亲不认 / Liù qīn búrèn / [성어] / 육친을 인정하지 않는다

- 의미: 부모, 형제, 처자 등 육친조차 인정하지 않을 정도로 냉혹하고 무정함. 또는 사리에 어두워 가까운 사람도 알아보지 못함을 이른다.
- 글자별 풀이:
  - 六 (liù): 여섯 육 — 여섯
  - 亲 (qīn): 친척 친 — 친척, 가까운
  - 不 (bù): 아닐 불 — 아니다, 부정
  - 认 (rèn): 인정할 인 — 인정하다, 알아보다
- 유의어:
  - 六亲无靠 (liù qīn wú kào): 육친이 도와줄 수 없다
  - 无情无义 (wú qíng wú yì): 정이 없고 의리가 없다

### 65. 六神无主 / Liù shén wú zhǔ / [성어] / 육신의 신이 주인이 없다

- 의미: 여섯 가지 정신(심, 폐, 간, 신, 비, 담)이 주인을 잃었다는 뜻으로, 너무 놀라거나 당황하여 마음의 중심을 잡지 못하고 어찌할 바를 모름.
- 글자별 풀이:
  - 六 (liù): 여섯 육 — 여섯
  - 神 (shén): 신 신 — 신, 정신
  - 无 (wú): 없을 무 — 없다, 부정
  - 主 (zhǔ): 주인 주 — 주인, 주도
- 유의어:
  - 心烦意乱 (xīn fán yì luàn): 마음이 번거롭고 뜻이 어지럽다
  - 惶惶不安 (huáng huáng bù ān): 불안해하고 안심하지 못한다

### 66. 七拼八凑 / Qī pīn bā còu / [성어] / 일곱 가지로 이으면 여덟

- 의미: 이것저것 닥치는 대로 모아서 억지로 맞추거나 엮어 냄. 재료나 자금 등을 여러 곳에서 급하게 끌어모아 임시방편으로 처리함을 이른다.
- 글자별 풀이:
  - 七 (qī): 일곱 칠 — 일곱
  - 拼 (pīn): 이을 편 — 이으면서 놀다
  - 八 (bā): 여덟 팔 — 여덟
  - 凑 (còu): 모을 주 — 모으다, 함께하다
- 유의어:
  - 临时抱佛脚 (lín shí bào fó jiǎo): 급할 때 부처 발을 안는다
  - 拆东墙补西墙 (chāi dōng qiáng bǔ xī qiáng): 동쪽 벽을 헐어 서쪽 벽을 수선한다

### 67. 七上八下 / Qī shàng bā xià / [성어] / 일곱 위 여덟 아래

- 의미: 일곱 번 올라갔다 여덟 번 내려왔다 하듯, 마음이 불안정하여 조마조마하고 초조한 상태를 비유.
- 글자별 풀이:
  - 七 (qī): 일곱 칠 — 일곱
  - 上 (shàng): 위 상 — 위, 위쪽
  - 八 (bā): 여덟 팔 — 여덟
  - 下 (xià): 아래 하 — 아래, 아래쪽
- 유의어:
  - 心里七上八下 (xīn lǐ qī shàng bā xià): 마음이 불안정하다
  - 忐忑不安 (tǎn tè bù ān): 불안정하고 안심하지 못한다

---

### 68. 七窍生烟 / Qī qiào shēng yān / [성어] / 일곱 구멍에서 연기가 난다

- 의미: 일곱 구멍(두 눈, 두 귀, 두 콧구멍, 입)에서 연기가 날 정도로 몹시 화가 나서 분노가 치밀어 오름을 형용.
- 글자별 풀이:
  - 七 (qī): 일곱 칠 — 일곱
  - 窍 (qiào): 구멍 교 — 구멍, 숨겨진 길
  - 生 (shēng): 날 생 — 낳다, 생기다
  - 烟 (yān): 연기 연 — 연기, 연
- 유의어:
  - 怒发冲冠 (nù fā chōng guàn): 화가 나서 머리가 관을 치고 솟는다
  - 勃然大怒 (bó rán dà nù): 갑자기 크게 화난다

---

### 69. 与世无争 / Yǔ shì wú zhēng / [성어] / 세상과 다투지 않는다

- 의미: 세상의 명예나 이익을 다투지 않고 모든 일에 초연한 태도를 취함. 속세의 다툼에서 벗어나 평화롭게 지내는 삶의 자세를 이른다.
- 글자별 풀이:
  - 与 (yǔ): 주다 여 — 함께하다, ~와
  - 世 (shì): 세상 세 — 세상, 시대
  - 无 (wú): 없을 무 — 없다, 부정
  - 争 (zhēng): 다툴 쟁 — 다투다, 경쟁하다
- 유의어:
  - 不争不扰 (bù zhēng bù rǎo): 다투지 않고 방해하지 않는다
  - 淡泊明志 (dàn báo míng zhì): 담백함이 명확한 뜻을 나타낸다

---

### 70. 与众不同 / Yǔ zhòng bù tóng / [성어] / 여럿과 다르다

- 의미: 여러 사람이나 일반적인 것과는 확연히 다르다는 뜻으로, 개성이나 특성이 뚜렷하여 남다름을 이르는 말.
- 글자별 풀이:
  - 与 (yǔ): 주다 여 — 함께하다, ~와
  - 众 (zhòng): 많을 중 — 많은, 여럿
  - 不 (bù): 아닐 불 — 아니다, 부정
  - 同 (tóng): 같을 동 — 같다, 같은
- 유의어:
  - 独树一帜 (dú shù yī zhì): 혼자 기치를 세우다
  - 与众不一样 (yǔ zhòng bù yí yàng): 여럿과 한 가지가 아니다

---

### 71. 开天辟地 / Kāi tiān pì dì / [성어] / 하늘을 열고 땅을 뜨다

- 의미: 물이 불어나면 배가 자연히 높이 뜨게 된다는 뜻으로, 기초나 바탕이 좋아지면 그에 딸린 것들도 함께 향상됨을 비유.
- 글자별 풀이:
  - 水 (shuǐ): 물 수 — 물, 수심
  - 涨 (zhǎng): 불 창 — 부풀다, 오르다
  - 船 (chuán): 배 선 — 배, 선박
  - 高 (gāo): 높을 고 — 높다, 올라가다
- 유의어:
  - 乘势而上 (chéng shì ér shàng): 형세를 타서 올라간다
  - 形势好转 (xíng shì hǎo zhuǎn): 형세가 좋아진다

### 93. 水清无鱼 / Shuǐ qīng wú yú / [성어] / 물이 맑으면 물고기가 없다

  - 无 (wú): 없을 무 — 없다, 무
  - 鱼 (yú): 물고기 어 — 물고기, 수산물
- 유의어:
  - 过于严格 (guò yú yán gé): 너무 엄격하다

### 94. 火树银花 / Huǒ shù yín huā / [성어] / 불의 나무 은색 꽃

### 97. 厚积薄发 / Hòu jī báo fā / [성어] / 두텁게 쌓아 얇게 터뜨린다

### 99. 后来居上 / Hòu lái jū shàng / [성어] / 나중 온 것이 위에 거한다
