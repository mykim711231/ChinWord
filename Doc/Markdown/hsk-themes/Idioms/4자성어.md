# 4자성어 (四字成語)

> 상황: 중국 고전에서 유래한 유명한 4자성어
> 수준: 광범위 학습 (200개)
> 단어 수: 200개 (현재 3개 샘플)

---

### 1. 温故知新 / Wēn gù zhī xīn / [성어] / 옛것을 익히고 새것을 안다

- 원문: 温故而知新，可以为师矣 (Wēn gù ér zhī xīn, kě yǐ wéi shī yǐ) — 『논어』 위정편(为政篇)
- 유래: 공자가 "옛것을 익히고 새것을 알면 스승이 될 수 있다"고 한 데서 유래. 단순 암기가 아닌, 배운 것에서 새로운 의미를 발견하는 태도를 강조.
- 글자별 풀이:
  - 温 (wēn): 따뜻할 온 — 데우다, 다시 익히다, 따뜻하다
  - 故 (gù): 옛 고 — 지나간 일, 이미 배운 것, 이유
  - 知 (zhī): 알 지 — 알다, 깨닫다, 이해하다
  - 新 (xīn): 새 신 — 새롭다, 새로운 지식, 처음
- 유의어:
  - 学而时习 (xué ér shí xí): 배우고 때때로 익히다
  - 鉴往知来 (jiàn wǎng zhī lái): 과거를 거울삼아 미래를 알다
  - 举一反三 (jǔ yī fǎn sān): 하나를 들어서 셋을 미루어 알다

### 2. 卧虎藏龙 / Wò hǔ cáng lóng / [성어] / 숨겨진 인재가 많다

- 원문: 卧虎藏龙 (Wò hǔ cáng lóng) — 중국 고대 민간 이야기
- 유래: 호랑이와 용이 숨어있다는 뜻으로, 표면에는 드러나지 않지만 뛰어난 인재나 능력이 감춰져 있음을 의미. 영화 "와호장룡"으로도 유명.
- 글자별 풀이:
  - 卧 (wò): 누울 와 — 누워있다, 숨어있다, 웅크리다
  - 虎 (hǔ): 호랑이 호 — 호랑이, 맹수, 강함
  - 藏 (cáng): 숨길 장 — 숨기다, 감춘다, 은폐하다
  - 龙 (lóng): 용 용 — 용, 비의상징, 최고의 것
- 유의어:
  - 藏龙卧虎 (cáng lóng wò hǔ): 용과 호랑이가 숨어있다
  - 人杰地灵 (rén jié dì líng): 사람이 뛰어나고 땅이 영험하다
  - 深藏不露 (shēn cáng bù lù): 깊이 숨겨져 드러나지 않다

### 3. 画龙点睛 / Huà lóng diǎn jīng / [성어] / 마지막에 핵심을 더해 완성하다

- 원문: 画龙点睛 (Huà lóng diǎn jīng) — 『晋书』 안도편(安都篇)
- 유래: 용을 그릴 때 눈을 그려 넣음으로써 완성된다는 뜻. 어떤 일이 거의 완성되었을 때 마지막으로 중요한 것을 더함으로써 비로소 완벽해짐을 의미.
- 글자별 풀이:
  - 画 (huà): 그릴 화 — 그리다, 그림, 도형
  - 龙 (lóng): 용 용 — 용, 비의상징, 최고의 것
  - 点 (diǎn): 찍을 점 — 점, 찍다, 표시
  - 睛 (jīng): 눈동자 정 — 눈, 시력, 명확함
- 유의어:
  - 锦上添花 (jǐn shàng tiān huā): 비단 위에 꽃을 더하다
  - 妙笔生花 (miào bǐ shēng huā): 묘한 붓으로 꽃을 피우다
  - 完美无缺 (wán měi wú quē): 완벽하고 부족함이 없다
