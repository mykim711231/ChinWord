# HSK 3.0 주제별 단어 마크다운 소스

> HSK 3.0 어휘(`app/src/data/hsk-words.json`, 10,969개)를 **주제별 학습 단위**로
> 손수 큐레이션하는 작업 폴더. UI(`/hsk/:tier`)의 "주제 필터(준비 중)" 영역은
> 여기서 생성되는 마크다운을 후속 파이프라인으로 파싱해 활성화될 예정이다.

## 2. 마크다운 포맷

ChinWord 의 기존 마크다운 소스에는 **두 가지** 포맷이 있다.
- **단어 포맷** — `Doc/Markdown/situations/*.md` (일반 어휘): 부수 분해 중심
- **성어 포맷** — `Doc/Markdown/idioms/*.md` (4자성어/관용구): 글자 의미·원문·유래 중심

`hsk-themes/` 의 단어 파일(Basic/, Mid/, 그리고 Adv/ 의 일반 도메인)은 **단어 포맷**을,
Adv/ 의 4자성어 도메인(예: `d09_4자성어.md`)은 **성어 포맷**을 사용한다.

### 2.1 단어 포맷 (situations 패턴)

```markdown
# 주제명 (中文 주제명, Pinyin)

> 상황: <학습 맥락 1줄 설명>
> 수준: HSK <X>급 중심
> 단어 수: <N>개

---

### 1. 한자 / pīnyīn / [품사] / 한국어 의미

- 한자 풀이:
  - 한자1: 부수(부수명) + 부수(부수명) → 자의(字義)
  - 한자2: 부수(부수명) + 부수(부수명) → 자의
- HSK 등급: <N>급

---
```

#### 작성 규칙

| 항목 | 규칙 |
|---|---|
| 단어 출처 | `app/src/data/hsk-words.json` 에 이미 존재하는 단어만 사용 (id 매칭 가능해야 함) |
| 한국어 의미 | 한국 중국어 학습자가 쓰는 자연스러운 사전식 뜻. 거짓동족어(false friend) 주의 — 工夫→시간/노력 (X 공부), 颜色→색깔 (X 안색), 放假→방학하다 (X 휴가) |
| 품사 | `[명사]` `[동사]` `[형용사]` `[부사]` `[양사]` `[조동사]` `[접속사]` `[대명사]` `[조사]` `[감탄사]` 중 하나. 다품사 시 `[명사/동사]` |
| 한자 풀이 | 1글자당 1줄. 부수는 한국 한자 부수명(亻=사람인변, 氵=삼수변 등). 자의는 5~15자 |
| HSK 등급 | 1~7 중 단어의 원 등급(테마 폴더가 Mid여도 단어 자체는 5급이 아닐 수 있음, 명시 필수) |

### 2.2 성어 포맷 (idioms 패턴) — 4자성어 도메인 전용

```markdown
# 주제명 (中文 주제명, Pinyin)

> 주제: <학습 맥락>
> 수준: HSK <X>급 중심 (또는 중급 이상 등)
> 성어 수: <N>개

---

### 1. 성어한자 / Pīnyīn / [성어] / 한국어 의미

- 의미: <2~3 문장 한국어 뜻 풀이> (출전: 『출전명』 편명) — 출전이 실존할 때만 기재
- 글자별 풀이:
  - 한자1 (pīnyīn): 훈음 — 자의/의미
  - 한자2 (pīnyīn): 훈음 — 자의/의미
- 유의어:
  - 유의성어 (pīnyīn): 한국어 뜻
  - 유의성어 (pīnyīn): 한국어 뜻

---
```

#### 단어 vs 성어 포맷 비교

| 항목 | 단어 (situations) | 성어 (idioms) |
|---|---|---|
| frontmatter 라벨 | `> 상황:` | `> 주제:` |
| 단위 라벨 | `> 단어 수: N개` | `> 성어 수: N개` |
| 품사 태그 | `[명사]/[동사]/[형용사]/...` | `[성어]` 고정 |
| 캐릭터별 풀이 라벨 | `- 한자 풀이:` (부수 분해) | `- 글자별 풀이:` (훈음+의미) |
| 캐릭터 풀이 라인 | `한자: 부수(이름) + 부수(이름) → 자의` | `한자 (pīnyīn): 훈음 — 의미` |
| 등급 표기 | `- HSK 등급: N급` (필수) | (없음 — 성어 자체에 HSK 매핑이 약함) |
| 추가 섹션 | 없음 | `- 의미:` / `- 글자별 풀이:` / `- 유의어:` |

> **왜 다른가?** 일반 단어는 부수에서 의미를 추론하는 학습이 효과적이지만,
> 4자성어는 각 글자가 독립적 의미 단위로 작용하고 **뜻·맥락**이 중요해 별도 포맷이
> 필요. UI 렌더링도 `VocabDetail` (한자 풀이) vs `IdiomDetail` (의미 + 글자별 풀이 + 유의어)
> 으로 분기된다.

### 2.3 ID 추적 (선택)

후속 파이프라인이 단어/성어를 데이터 JSON과 매칭할 수 있도록, 작성자가 원하면
각 항목 끝에 hidden HTML 주석으로 id를 남길 수 있다:

```markdown
### 5. 后悔 / hòu huǐ / [동사] / 후회하다, 뉘우치다

- 한자 풀이:
  - 后: 厂(민엄호) + 一(한일) + 口(입구) → 뒤, 후
  - 悔: 忄(심방변) + 每(매양매) → 뉘우치다, 후회
- HSK 등급: 5급

<!-- id: hsk_5_0174 -->
```

ID 주석이 없으면 파이프라인이 `(simplified, pinyin)` 쌍으로 fuzzy 매칭한다.

## 3. 작성 워크플로

1. HSK 등급 + 주제 후보 선정 (예: HSK 5 · 감정/심리)
2. `hsk-words.json` 에서 후보 단어 grep (영문 meaning 키워드로 1차 필터)
3. 작성자가 hand-curate (보통 1주제당 20~60 단어, 성어는 1주제당 50개)
4. 위 포맷으로 마크다운 작성, PR
5. `build-content.ts` (예정) 가 파싱하여 `hsk-themes.json` 생성
6. `HskTier.tsx` 의 placeholder UI 가 활성화됨
