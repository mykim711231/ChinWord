# 감정과 심리 (情感与心理, Qínggǎn yǔ xīnlǐ)

> 상황: 기쁨·슬픔·후회·기대 등 감정 표현, 성격/태도/마음 상태 묘사
> 수준: HSK 5급 중심
> 단어 수: 15개

### 1. 讨厌 / tǎo yàn / [동사/형용사] / 싫어하다, 짜증나다, 성가시다

- 한자 풀이:
  - 讨: 讠(말씀언변) + 寸(마디촌) → 토론하다, 요구하다, 싫다
  - 厌: 厂(민엄호) + 犬(개견) → 싫증나다, 물리다
- HSK 등급: 5급

### 5. 恋爱 / liàn ài / [동사/명사] / 연애하다, 사랑에 빠지다

- 한자 풀이:
  - 恋: 亦(또역) + 心(마음심) → 그리워하다, 사랑하다
  - 爱: 爫(손톱조) + 冖(덮을멱) + 友(벗우) → 사랑하다, 아끼다
- HSK 등급: 5급

### 14. 不耐烦 / bù nài fán / [형용사] / 짜증나다, 귀찮다, 견디기 어려워하다

- 한자 풀이:
  - 不: 一(한일) + 丶(점주) → 아니다, 부정
  - 耐: 而(말이을이) + 寸(마디촌) → 견디다, 참다
  - 烦: 火(불화) + 页(머리혈) → 번거롭다, 귀찮다
- HSK 등급: 5급

### 15. 心疼 / xīn téng / [동사] / 안쓰러워하다, 애지중지하다, 아까워하다

- 한자 풀이:
  - 心: 心(마음심) → 마음, 심장
  - 疼: 疒(병질엄) + 冬(겨울동) → 아프다, 가엾이 여기다
- HSK 등급: 5급
