# 무역과 계약 (贸易与合同, Màoyì yǔ hétong)

> 상황: 국제 무역, 계약서, 수출입, 물류 관련 업무 표현
> 수준: HSK 4~5급 중심
> 단어 수: 25개

---

### 1. 贸易 / màoyì / [명사] / 무역

- 한자 풀이:
  - 贸: 卯(토끼모) + 贝(조개패) → 재화(贝)를 교류하다 → 무역하다, 거래하다
  - 易: 日(날일) + 勿(말물) → 변화하다, 쉽다 → 교역, 무역
- HSK 등급: 5급

---

### 2. 合同 / hétong / [명사] / 계약서

- 한자 풀이:
  - 合: 人(사람인) + 一(한일) + 口(입구) → 사람의 입을 하나로 모으다 → 합하다, 맞추다
  - 同: 冂(멀경몸) + 一(한일) + 口(입구) → 모두 함께 말하다 → 같다, 함께, 동일
- HSK 등급: 5급

---

### 3. 协议 / xiéyì / [명사] / 협의, 합의

- 한자 풀이:
  - 协: 十(열십) + 办(힘쓸판) → 열 사람이 힘을 합치다 → 협력하다
  - 议: 讠(말씀언변) + 义(옳을의) → 옳은 말을 나누다 → 의논, 합의
- HSK 등급: 5급

---

### 4. 条款 / tiáokuǎn / [명사] / 조항

- 한자 풀이:
  - 条: 夂(뒤져올치) + 木(나무목) → 나뭇가지 → 조목, 조항
  - 款: 士(선비사) + 示(보일시) + 欠(하품흠) → 문서에 적힌 조목 → 조항, 항목
- HSK 등급: 5급

---

### 5. 签订 / qiāndìng / [동사] / 체결하다

- 한자 풀이:
  - 签: ⺮(대죽) + 佥(모두첨) → 대쪽에 이름을 쓰다 → 서명하다
  - 订: 讠(말씀언변) + 丁(못정) → 말로 약속을 단단히 정하다 → 정하다, 체결하다
- HSK 등급: 5급

---

### 6. 出口 / chūkǒu / [명사/동사] / 수출(하다)

- 한자 풀이:
  - 出: 凵(입벌릴감) + 山(메산) → 산에서 나오다 → 나가다, 내다
  - 口: 口(입구) → 입구, 항구 → 출구, 수출
- HSK 등급: 4급

---

### 7. 进口 / jìnkǒu / [명사/동사] / 수입(하다)

- 한자 풀이:

  - 口: 口(입구) → 입구 → 수입

---

### 8. 海关 / hǎiguān / [명사] / 세관

- 한자 풀이:

  - 关: 丷(여덟팔) + 天(하늘천) → 빗장을 지르다 → 관문, 세관
