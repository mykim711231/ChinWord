# 부동산과 주거 (房产与居住, Fángchǎn yǔ jūzhù)

> 상황: 부동산, 임대, 이사, 주거 환경 관련 어휘
> 수준: HSK 4~5급 중심
> 단어 수: 25개

---

### 1. 房子 / fángzi / [명사] / 집, 주택

- 한자 풀이:
  - 房: 户(지게호) + 方(모방) → 방, 집
  - 子: 子(아들자) → 명사 접미사
- HSK 등급: 4급

---

### 2. 公寓 / gōngyù / [명사] / 아파트

- 한자 풀이:
  - 公: 八(여덟팔) + 厶(사사사) → 공공의, 공적인
  - 寓: 宀(갓머리) + 禺 → 거주하다, 주택
- HSK 등급: 5급

---
