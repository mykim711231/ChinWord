# 쇼핑과 흥정 (购物与讲价, Gòuwù yǔ jiǎngjià)

> 상황: 가격 묻기, 색상, 사이즈, 흥정
> 수준: HSK 1~3급 중심
> 단어 수: 25개

---

### 1. 买 / Mǎi / [동사] / 사다

- 한자 풀이:
  - 买: 乛(또을) + 头(머리두) → 사다, 구입하다(그물[罒]과 조개[贝]의 의미)
- HSK 등급: 1급

---

### 2. 卖 / Mài / [동사] / 팔다

- 한자 풀이:
  - 卖: 十(열십) + 买(살매) → 팔다(물건을 내다 팖)
- HSK 등급: 1급

---

### 3. 商店 / Shāngdiàn / [명사] / 상점

- 한자 풀이:
  - 商: 亠(돼지해머리) + 冏(밝을경) + 八(여덟팔) + 口(입구) → 장사, 상업(장사치가 말하는 모양)
  - 店: 广(엄호) + 占(차지할점) → 가게, 점포
- HSK 등급: 1급

---

### 4. 超市 / Chāoshì / [명사] / 슈퍼마켓

- 한자 풀이:
  - 超: 走(달릴주) + 召(부를소) → 넘다, 초월하다
  - 市: 亠(돼지해머리) + 巾(수건건) → 시장, 도시
- HSK 등급: 2급

---

### 5. 市场 / Shìchǎng / [명사] / 시장

- 한자 풀이:
  - 市: 亠(돼지해머리) + 巾(수건건) → 시장
  - 场: 土(흙토) + 昜(햇살양) → 장소, 마당
- HSK 등급: 2급

---

### 6. 钱 / Qián / [명사] / 돈

- 한자 풀이:
  - 钱: 钅(쇠금변) + 戋(자을전) → 돈, 화폐(쇠로 만든 돈)
- HSK 등급: 1급

---

### 7. 多少钱 / Duōshǎo qián / [의문구] / 얼마입니까

- 한자 풀이:
  - 多: 夕(저녁석) + 夕(저녁석) → 많다(저녁이 거듭되어 많음)
  - 少: 小(작을소) + 丿(삐침) → 적다
  - 钱: 钅(쇠금변) + 戋(자을전) → 돈
- HSK 등급: 1급

---

### 8. 元 / Yuán / [양사] / 위안(화폐단위)

- 한자 풀이:
  - 元: 二(두이) + 儿(어진사람인) → 기본 단위, 으뜸
- HSK 등급: 1급

---

### 9. 块 / Kuài / [양사] / 위안(구어)

- 한자 풀이:
  - 块: 土(흙토) + 夬(패괘괴) → 덩어리(흙 덩어리에서 '덩이', '조각'으로)
- HSK 등급: 1급

---

### 10. 毛 / Máo / [양사] / 마오(1/10위안)

- 한자 풀이:
  - 毛: 毛(터럭모) → 털, 아주 작은 단위에서 '잔돈'을 뜻함
- HSK 등급: 2급

---

### 11. 贵 / Guì / [형용사] / 비싸다

- 한자 풀이:
  - 贵: ⺋(머리) + 一(한일) + 目(눈목) + 贝(조개패) → 귀하다, 비싸다(조개패[돈]이 귀함)
- HSK 등급: 1급

---

### 12. 便宜 / Piányi / [형용사] / 싸다

- 한자 풀이:
  - 便: 亻(사람인변) + 更(고칠경) → 편하다, 편리하다
  - 宜: 宀(갓머리) + 且(또차) → 마땅하다, 알맞다
- HSK 등급: 1급

---

### 13. 打折 / Dǎzhé / [동사] / 할인하다

- 한자 풀이:
  - 打: 扌(손수변) + 丁(못정) → 치다, 하다(손으로 치는 동작)
  - 折: 扌(손수변) + 斤(도끼근) → 꺾다, 할인하다(가격을 꺾음)
- HSK 등급: 3급

---

### 14. 大 / Dà / [형용사] / 크다

- 한자 풀이:
  - 大: 大(큰대) → 크다(사람이 양팔을 벌린 모양)
- HSK 등급: 1급

---

### 15. 小 / Xiǎo / [형용사] / 작다

- 한자 풀이:
  - 小: 小(작을소) → 작다(세 점으로 작은 것을 나타냄)
- HSK 등급: 1급

---

### 16. 衣服 / Yīfu / [명사] / 옷

- 한자 풀이:
  - 衣: 衣(옷의) → 옷(옷깃 모양을 본뜬 글자)
  - 服: 月(육달월) + 卩(병부절) + 又(또우) → 옷을 입다, 복종하다
- HSK 등급: 1급

---

### 17. 鞋 / Xié / [명사] / 신발

- 한자 풀이:
  - 鞋: 革(가죽혁) + 圭(홀규) → 신발(가죽으로 만든 신발)
- HSK 등급: 2급

---

### 18. 颜色 / Yánsè / [명사] / 색깔

- 한자 풀이:
  - 颜: 彦(선비언) + 页(머리혈) → 얼굴(머리와 관련), 색깔로 확장
  - 色: 色(빛색) → 색
- HSK 등급: 1급

---

### 19. 红色 / Hóngsè / [명사] / 빨간색

- 한자 풀이:
  - 红: 纟(실사변) + 工(장인공) → 붉다(붉은 실)
  - 色: 色(빛색) → 색
- HSK 등급: 1급

---

### 20. 白色 / Báisè / [명사] / 흰색

- 한자 풀이:
  - 白: 白(흰백) → 희다(해의 빛 또는 쌀알의 빛깔에서 유래)
  - 色: 色(빛색) → 색
- HSK 등급: 1급

---

### 21. 黑色 / Hēisè / [명사] / 검은색

- 한자 풀이:
  - 黑: 黑(검을흑) → 검다(불 그을린 아궁이 모양)
  - 色: 色(빛색) → 색
- HSK 등급: 1급

---

### 22. 个 / Gè / [양사] / 개(범용 양사)

- 한자 풀이:
  - 个: 人(사람인) + 丨(뚫을곤) → 범용 양사(원래는 대나무 줄기를 셈)
- HSK 등급: 1급

---

### 23. 件 / Jiàn / [양사] / 벌(옷 양사)

- 한자 풀이:
  - 件: 亻(사람인변) + 牛(소우) → 물건, 양사(사람이 소를 나누듯 구분)
- HSK 등급: 2급

---

### 24. 双 / Shuāng / [양사] / 켤레(신발 양사)

- 한자 풀이:
  - 双: 又(또우) + 又(또우) → 두 개, 쌍(두 손을 나란히)
- HSK 등급: 2급

---

### 25. 试 / Shì / [동사] / 시험해보다, 입어보다

- 한자 풀이:
  - 试: 讠(말씀언변) + 式(법식) → 시험하다, 시도하다(말로 규칙을 적용해 봄)
- HSK 등급: 2급
