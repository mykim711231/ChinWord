# 가족과 친구 (家庭与朋友, Jiātíng yǔ péngyǒu)

> 상황: 가족 소개, 친구 관계, 호칭
> 수준: HSK 1~2급 중심
> 단어 수: 25개

---

### 1. 家 / Jiā / [명사] / 집, 가족

- 한자 풀이:
  - 家: 宀(갓머리) + 豕(돼지시) → 지붕 아래 돼지를 기르는 집, '집'과 '가족'을 뜻함
- HSK 등급: 1급

---

### 2. 爸爸 / Bàba / [명사] / 아빠

- 한자 풀이:
  - 爸: 父(아비부) + 巴(땅이름파) → 아버지(父가 의미, 巴가 소리 요소)
- HSK 등급: 1급

---

### 3. 妈妈 / Māma / [명사] / 엄마

- 한자 풀이:
  - 妈: 女(계집녀) + 马(말마) → 어머니(女가 의미, 马가 소리 요소)
- HSK 등급: 1급

---

### 4. 哥哥 / Gēge / [명사] / 형, 오빠

- 한자 풀이:
  - 哥: 可(옳을가) + 可(옳을가) → '노래하다'의 본뜻에서 가족 호칭으로 확장
- HSK 등급: 1급

---

### 5. 弟弟 / Dìdi / [명사] / 남동생

- 한자 풀이:
  - 弟: 丷(여덟팔) + 弓(활궁) + 丨(뚫을곤) + 丿(삐침) → 활시위 순서, '아우'를 뜻함
- HSK 등급: 2급

---

### 6. 姐姐 / Jiějie / [명사] / 언니, 누나

- 한자 풀이:
  - 姐: 女(계집녀) + 且(또차) → 언니(女가 의미, 且가 소리 요소)
- HSK 등급: 1급

---

### 7. 妹妹 / Mèimei / [명사] / 여동생

- 한자 풀이:
  - 妹: 女(계집녀) + 未(아닐미) → 여동생(未는 소리 요소)
- HSK 등급: 1급

---

### 8. 儿子 / Érzi / [명사] / 아들

- 한자 풀이:
  - 儿: 儿(어진사람인) → 아이, 사람
  - 子: 子(아들자) → 자식
- HSK 등급: 1급

---

### 9. 女儿 / Nǚ'ér / [명사] / 딸

- 한자 풀이:
  - 女: 女(계집녀) → 여자
  - 儿: 儿(어진사람인) → 아이, 사람
- HSK 등급: 1급

---

### 10. 丈夫 / Zhàngfu / [명사] / 남편

- 한자 풀이:
  - 丈: 十(열십) + 又(또우) → 길이 단위에서 '어른', '지아비'로 확장
  - 夫: 二(두이) + 人(사람인) → 성인 남자, 지아비
- HSK 등급: 2급

---

### 11. 妻子 / Qīzi / [명사] / 아내

- 한자 풀이:
  - 妻: 一(한일) + 丨(뚫을곤) + 女(계집녀) + 又(또우) → 여자가 머리를 빗는 모양, '아내'
  - 子: 子(아들자) → (접미사)
- HSK 등급: 2급

---

### 12. 爷爷 / Yéye / [명사] / 할아버지

- 한자 풀이:
  - 爷: 父(아비부) + 卩(병부절) → 할아버지(父가 의미, 卩이 소리 요소)
- HSK 등급: 1급

---

### 13. 奶奶 / Nǎinai / [명사] / 할머니

- 한자 풀이:
  - 奶: 女(계집녀) + 乃(이에내) → 할머니, 젖(女가 의미, 乃가 소리 요소)
- HSK 등급: 1급

---

### 14. 朋友 / Péngyou / [명사] / 친구

- 한자 풀이:
  - 朋: 月(달월) + 月(달월) → 벗, 친구(달이 둘, 서로 비추는 의미)
  - 友: 𠂇(왼손좌) + 又(또우) → 벗(두 손을 마주잡은 모양)
- HSK 등급: 1급

---

### 15. 同学 / Tóngxué / [명사] / 동창, 학우

- 한자 풀이:
  - 同: 冂(멀경) + 一(한일) + 口(입구) → 같다, 함께
  - 学: ⺌(작을소머리) + 冖(덮을멱) + 子(아들자) → 배우다(아이가 지식 아래에서 배움)
- HSK 등급: 1급

---

### 16. 同事 / Tóngshì / [명사] / 동료

- 한자 풀이:
  - 同: 冂(멀경) + 一(한일) + 口(입구) → 같다, 함께
  - 事: 一(한일) + 口(입구) + 彐(튼가뢰) + 亅(갈고리) → 일, 사무
- HSK 등급: 2급

---

### 17. 邻居 / Línjū / [명사] / 이웃

- 한자 풀이:
  - 邻: 令(하여금령) + 阝(우부변) → 이웃(令이 소리, 阝가 '마을'을 뜻함)
  - 居: 尸(주검시) + 古(예고) → 살다, 거주하다
- HSK 등급: 2급

---

### 18. 孩子 / Háizi / [명사] / 아이

- 한자 풀이:
  - 孩: 子(아들자) + 亥(돼지해) → 아이, 어린이(子가 의미, 亥가 소리)
  - 子: 子(아들자) → (접미사)
- HSK 등급: 1급

---

### 19. 年轻 / Niánqīng / [형용사] / 젊다

- 한자 풀이:
  - 年: 禾(벼화) + 人(사람인) + 丶(점) → 해, 나이(사람이 벼를 이고 있는 모양)
  - 轻: 车(수레거) + 工(장인공) → 가볍다(수레에 짐이 적어 가벼움)
- HSK 등급: 2급

---

### 20. 老 / Lǎo / [형용사] / 나이가 많다

- 한자 풀이:
  - 老: 老(늙을로) → 늙다, 나이가 들다(지팡이를 짚은 노인 모양)
- HSK 등급: 1급

---

### 21. 男 / Nán / [형용사] / 남성

- 한자 풀이:
  - 男: 田(밭전) + 力(힘력) → 밭에서 힘쓰는 사람, '남자'
- HSK 등급: 1급

---

### 22. 女 / Nǚ / [형용사] / 여성

- 한자 풀이:
  - 女: 女(계집녀) → 여자(무릎 꿇고 앉은 여성의 모양)
- HSK 등급: 1급

---

### 23. 结婚 / Jiéhūn / [동사] / 결혼하다

- 한자 풀이:
  - 结: 纟(실사변) + 吉(길할길) → 맺다, 결합하다(실로 길하게 맺음)
  - 婚: 女(계집녀) + 昏(어두울혼) → 혼인(여자가 저녁[昏]에 시집가는 풍속)
- HSK 등급: 2급

---

### 24. 关系 / Guānxi / [명사] / 관계

- 한자 풀이:
  - 关: 丷(여덟팔머리) + 天(하늘천) → 빗장을 걸다, 관계하다
  - 系: 丿(삐침) + 糸(실사) → 계통, 연결되다
- HSK 등급: 2급

---

### 25. 照顾 / Zhàogù / [동사] / 돌보다

- 한자 풀이:
  - 照: 日(날일) + 召(부를소) + 灬(연화발) → 비추다(해가 밝게 비춤)
  - 顾: 雇(품팔고) + 页(머리혈) → 돌보다, 살피다(머리를 돌려 봄)
- HSK 등급: 2급
