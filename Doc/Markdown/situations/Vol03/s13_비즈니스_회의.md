# 비즈니스 회의 (商务会议, Shāngwù huìyì)

> 상황: 회의 진행, 발표, 협상, 프레젠테이션 관련 비즈니스 회의 표현
> 수준: HSK 4~5급 중심
> 단어 수: 25개

---

### 1. 会议 / huìyì / [명사] / 회의

- 한자 풀이:
  - 会: 人(사람인) + 云(구름운) → 사람이 구름처럼 모이다 → 모임, 회의
  - 议: 讠(말씀언변) + 义(옳을의) → 옳은 말을 나누다 → 의논, 회의
- HSK 등급: 4급

---

### 2. 议程 / yìchéng / [명사] / 의제

- 한자 풀이:
  - 议: 讠(말씀언변) + 义(옳을의) → 옳은 말을 나누다 → 의논, 회의
  - 程: 禾(벼화) + 呈(드릴정) → 벼의 생장 과정처럼 단계를 밟다 → 과정, 절차
- HSK 등급: 5급

---

### 3. 报告 / bàogào / [명사/동사] / 보고(하다)

- 한자 풀이:
  - 报: 扌(손수변) + 卩(병부절) → 죄인을 잡아 알리다 → 보고하다
  - 告: 牛(소우) + 口(입구) → 소를 제사 지내며 신에게 고하다 → 알리다, 고하다
- HSK 등급: 4급

---

### 4. 演讲 / yǎnjiǎng / [명사/동사] / 연설(하다)

- 한자 풀이:
  - 演: 氵(삼수변) + 寅(셋째지지인) → 물이 흐르듯 말을 펼치다 → 연설하다
  - 讲: 讠(말씀언변) + 井(우물정) → 우물가에서 이야기하다 → 강연하다
- HSK 등급: 5급

---

### 5. 讨论 / tǎolùn / [동사] / 토론하다

- 한자 풀이:
  - 讨: 讠(말씀언변) + 寸(마디촌) → 법도(寸)에 따라 비판적으로 말하다 → 토론하다
  - 论: 讠(말씀언변) + 仑(생각할륜) → 의견을 모아 말하다 → 논의하다
- HSK 등급: 4급

---

### 6. 提案 / tí'àn / [명사] / 제안

- 한자 풀이:
  - 提: 扌(손수변) + 是(바를시) → 손으로 들어 올려 바르게 하다 → 제기하다, 제출하다
  - 案: 安(편안할안) + 木(나무목) → 안건을 올리는 나무 책상 → 안건, 제안
- HSK 등급: 5급

---

### 7. 决定 / juédìng / [동사/명사] / 결정(하다)

- 한자 풀이:
  - 决: 冫(이수변) + 夬(결단할괘) → 얼음이 갈라지듯 단호히 결단하다 → 결정하다
  - 定: 宀(갓머리) + 正(바를정) → 집 안에서 바로잡다 → 정하다, 결정하다
- HSK 등급: 4급

---

### 8. 确认 / quèrèn / [동사] / 확인하다

- 한자 풀이:
  - 确: 石(돌석) + 角(뿔각) → 돌처럼 단단하고 확실한 → 확실하다, 정확하다
  - 认: 讠(말씀언변) + 人(사람인) → 사람을 알아보다 → 인식하다, 확인하다
- HSK 등급: 4급

---

### 9. 协商 / xiéshāng / [동사] / 협의하다

- 한자 풀이:
  - 协: 十(열십) + 办(힘쓸판) → 열 사람이 힘을 합치다 → 협력하다, 협의하다
  - 商: 亠(돼지해머리) + (丷+冂+八+口) → 함께 모여 의논하다 → 상의하다, 의논하다
- HSK 등급: 5급

---

### 10. 谈判 / tánpàn / [명사/동사] / 협상(하다)

- 한자 풀이:
  - 谈: 讠(말씀언변) + 炎(불꽃염) → 불꽃처럼 열정적으로 말을 주고받다 → 담화하다, 이야기하다
  - 判: 半(반반) + 刂(선칼도방) → 반으로 갈라 판단하다 → 판단하다, 판결하다
- HSK 등급: 5급

---

### 11. 方案 / fāng'àn / [명사] / 방안

- 한자 풀이:
  - 方: 方(방패방) → 모서리, 방법 → 방향, 방식, 방법
  - 案: 安(편안할안) + 木(나무목) → 안건을 올리는 책상 → 안건, 방안
- HSK 등급: 5급

---

### 12. 目标 / mùbiāo / [명사] / 목표

- 한자 풀이:
  - 目: 目(눈목) → 눈으로 보는 것 → 목적, 항목
  - 标: 木(나무목) + 示(보일시) → 나무에 표시를 하다 → 표시, 목표
- HSK 등급: 4급

---

### 13. 策略 / cèlüè / [명사] / 전략

- 한자 풀이:
  - 策: ⺮(대죽) + 朿(가시자) → 대쪽에 적은 계획 → 계책, 전략
  - 略: 田(밭전) + 各(각각각) → 밭의 경계를 구분하다 → 전략, 약략
- HSK 등급: 5급

---

### 14. 执行 / zhíxíng / [동사] / 실행하다

- 한자 풀이:
  - 执: 扌(손수변) + 丸(알환) → 손에 움켜잡다 → 잡다, 집행하다
  - 行: 彳(두인변) + 亍(머무를축) → 걷다, 나아가다 → 가다, 실행하다
- HSK 등급: 5급

---

### 15. 结果 / jiéguǒ / [명사] / 결과

- 한자 풀이:
  - 结: 纟(실사변) + 吉(길할길) → 실을 맺다 → 맺다, 결과를 맺다
  - 果: 田(밭전) + 木(나무목) → 나무에 열린 열매 → 결과, 성과
- HSK 등급: 4급

---

### 16. 总结 / zǒngjié / [동사/명사] / 총괄(하다)

- 한자 풀이:
  - 总: ⺌(작을소머리) + 口(입구) + 心(마음심) → 모두 한마음으로 모으다 → 총괄하다
  - 结: 纟(실사변) + 吉(길할길) → 실을 맺다 → 맺다, 정리하다
- HSK 등급: 5급

---

### 17. 意见 / yìjiàn / [명사] / 의견

- 한자 풀이:
  - 意: 音(소리음) + 心(마음심) → 마음속의 소리 → 뜻, 의견
  - 见: 见(볼견) → 보다, 나타나다 → 견해, 의견
- HSK 등급: 4급

---

### 18. 建议 / jiànyì / [동사/명사] / 건의(하다)

- 한자 풀이:
  - 建: 廴(민책받침) + 聿(붓율) → 붓으로 법을 세우다 → 세우다, 건의하다
  - 议: 讠(말씀언변) + 义(옳을의) → 옳은 말을 나누다 → 의논하다, 제안하다
- HSK 등급: 4급

---

### 19. 反对 / fǎnduì / [동사] / 반대하다

- 한자 풀이:
  - 反: 厂(기슭엄) + 又(또우) → 절벽에 손을 대고 반대 방향으로 가다 → 반대하다
  - 对: 又(또우) + 寸(마디촌) → 법도에 맞게 대응하다 → 맞다, 대하다
- HSK 등급: 4급

---

### 20. 支持 / zhīchí / [동사] / 지지하다

- 한자 풀이:
  - 支: 十(열십) + 又(또우) → 손으로 받치다 → 지탱하다, 지지하다
  - 持: 扌(손수변) + 寺(절사) → 손에 들고 있다 → 가지다, 지지하다
- HSK 등급: 4급

---

### 21. 推迟 / tuīchí / [동사] / 연기하다

- 한자 풀이:
  - 推: 扌(손수변) + 隹(새추) → 새를 밀듯이 → 밀다, 미루다
  - 迟: 辶(책받침) + 尺(자척) → 발걸음이 느리다 → 늦다, 지연되다
- HSK 등급: 5급

---

### 22. 取消 / qǔxiāo / [동사] / 취소하다

- 한자 풀이:
  - 取: 耳(귀이) + 又(또우) → (전쟁에서) 귀를 자르다 → 취하다, 가져오다
  - 消: 氵(삼수변) + 肖(닮을초) → 물이 증발하여 사라지다 → 없애다, 소멸하다
- HSK 등급: 4급

---

### 23. 安排 / ānpái / [동사/명사] / 배치/스케줄(하다)

- 한자 풀이:
  - 安: 宀(갓머리) + 女(계집녀) → 집 안에 여자가 있어 편안하다 → 편안하다, 안정되다
  - 排: 扌(손수변) + 非(아닐비) → 손으로 밀어 배열하다 → 배열하다, 배치하다
- HSK 등급: 4급

---

### 24. 记录 / jìlù / [동사/명사] / 기록(하다)

- 한자 풀이:
  - 记: 讠(말씀언변) + 己(자기기) → 자기 말을 기록하다 → 기록하다, 적다
  - 录: 彐(돼지머리) + 氺(물수변밑) → 물에 비추듯 사실을 기록하다 → 기록
- HSK 등급: 4급

---

### 25. 跟进 / gēnjìn / [동사] / 후속 조치하다

- 한자 풀이:
  - 跟: 足(발족) + 艮(그칠간) → 발로 따라가다 → 따르다, 뒤따르다
  - 进: 辶(책받침) + 井(우물정) → 앞으로 나아가다 → 나아가다, 진입하다
- HSK 등급: 5급
