# 금융과 은행 (金融与银行, Jīnróng yǔ yínháng)

> 상황: 은행 업무, 투자, 환전, 세금 관련 금융 표현
> 수준: HSK 4~5급 중심
> 단어 수: 25개

---

### 1. 银行 / yínháng / [명사] / 은행

- 한자 풀이:
  - 银: 钅(쇠금변) + 艮(그칠간) → 은(금속) → 은, 은행
  - 行: 彳(두인변) + 亍(머무를축) → 걸어가다 → 가다, 행하다, (银行) 은행
- HSK 등급: 4급

---

### 2. 账户 / zhànghù / [명사] / 계좌

- 한자 풀이:
  - 账: 贝(조개패) + 长(긴장) → 돈의 내역을 길게 기록하다 → 장부, 계좌
  - 户: 户(지게호) → 문, 집 → 호구, 계정
- HSK 등급: 5급

---

### 3. 存款 / cúnkuǎn / [명사] / 예금

- 한자 풀이:
  - 存: 才(재주재) + 子(아들자) → 재주를 간직하다 → 존재하다, 저장하다
  - 款: 士(선비사) + 示(보일시) + 欠(하품흠) → 자금, 돈 → 금액, 예금
- HSK 등급: 5급

---

### 4. 取钱 / qǔqián / [동사] / 출금하다

- 한자 풀이:
  - 取: 耳(귀이) + 又(또우) → (전쟁에서) 귀를 베어 가지다 → 취하다, 가져오다
  - 钱: 钅(쇠금변) + 戋(작을전) → 돈, 화폐
- HSK 등급: 4급

---

### 5. 贷款 / dàikuǎn / [명사/동사] / 대출(하다)

- 한자 풀이:
  - 贷: 代(대신할대) + 贝(조개패) → 대신 빌리는 돈 → 대출, 빌리다
  - 款: 士(선비사) + 示(보일시) + 欠(하품흠) → 자금, 돈 → 금액, 대출금
- HSK 등급: 5급

---

### 6. 利息 / lìxī / [명사] / 이자

- 한자 풀이:
  - 利: 禾(벼화) + 刂(선칼도방) → 벼를 베는 칼처럼 날카로운 이익 → 이익, 이자
  - 息: 自(스스로자) + 心(마음심) → 자신의 심장 박동 → 숨쉬다, 이자
- HSK 등급: 5급

---

### 7. 汇率 / huìlǜ / [명사] / 환율

- 한자 풀이:
  - 汇: 氵(삼수변) + 匚(상자방) → 물이 모이다 → 모으다, 환전하다
  - 率: 亠(돼지해머리) + 玄(검을현) + 十(열십) → 기준을 정하다 → 비율, 율
- HSK 등급: 5급

---

### 8. 换钱 / huànqián / [동사] / 환전하다

- 한자 풀이:
  - 换: 扌(손수변) + 奂(클환) → 손으로 바꾸다 → 교환하다, 바꾸다
  - 钱: 钅(쇠금변) + 戋(작을전) → 돈, 화폐
- HSK 등급: 4급

---

### 9. 现金 / xiànjīn / [명사] / 현금

- 한자 풀이:
  - 现: 王(구슬옥변) + 见(볼견) → 구슬이 드러나 보이다 → 나타나다, 현금
  - 金: 人(사람인) + 王(왕왕) + 丶(점주) → 귀금속 → 쇠, 금, 돈
- HSK 등급: 5급

---

### 10. 信用卡 / xìnyòngkǎ / [명사] / 신용카드

- 한자 풀이:
  - 信: 亻(사람인변) + 言(말씀언) → 사람의 말은 믿을 만하다 → 믿다, 신용
  - 用: 用(쓸용) → 사용하다, 쓰다
  - 卡: 上(위상) + 下(아래하) 변형 → 위아래를 막다 → 카드
- HSK 등급: 4급

  - 票: 覀(덮을아) + 示(보일시) → 표시가 있는 문서 → 표, 증서

  - 险: 阝(좌부변) + 佥(모두첨) → 모두가 위험하다 여기다 → 위험, 험난함

  - 险: 阝(좌부변) + 佥(모두첨) → 모두가 위험하다 여기다 → 위험
