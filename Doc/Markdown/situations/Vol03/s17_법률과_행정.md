# 법률과 행정 (法律与行政, Fǎlǜ yǔ xíngzhèng)

> 상황: 법률 용어, 계약, 정부 행정, 공문서 관련 어휘
> 수준: HSK 4~5급 중심
> 단어 수: 25개

---

### 1. 法律 / fǎlǜ / [명사] / 법률

- 한자 풀이:
  - 法: 氵(삼수변) + 去(갈거) → 법, 방법
  - 律: 彳(두인변) + 聿(붓율) → 법칙, 규율
- HSK 등급: 4급

---

### 2. 合同 / hétong / [명사] / 계약

- 한자 풀이:
  - 合: 人(사람인) + 一(한일) + 口(입구) → 합하다, 맞다
  - 同: 冂(멀경) + 一(한일) + 口(입구) → 같다, 함께하다
- HSK 등급: 4급

---
