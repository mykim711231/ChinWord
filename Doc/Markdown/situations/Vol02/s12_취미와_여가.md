# 취미와 여가 (爱好与休闲, Àihào yǔ xiūxián)

> 상황: 운동, 음악, 영화, 여가 활동
> 수준: HSK 1~3급 중심
> 단어 수: 25개

---

### 1. 爱好 / àihào / [명사] / 취미, 애호

- 한자 풀이:
  - 爱: 爫(손톱조) + 冖(덮을멍) + 友(벗우) + 夂(뒤져을치) → 사랑하다
  - 好: 女(계집녀) + 子(아들자) → 좋아하다
- HSK 등급: 2급

---

### 2. 运动 / yùndòng / [명사/동사] / 운동(하다)

- 한자 풀이:
  - 运: 辶(책받침) + 云(이를운) → 옮기다, 운전하다
  - 动: 云(이를운) + 力(힘력) → 움직이다, 운동하다
- HSK 등급: 2급

---

### 3. 跑步 / pǎobù / [동사] / 달리기, 뛰다

  - 步: 止(그칠지) + 丶(점주) → 걸음, 단계
- HSK 등급: 2급

---

### 4. 游泳 / yóuyǒng / [동사] / 수영하다
