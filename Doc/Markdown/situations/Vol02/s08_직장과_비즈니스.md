# 직장과 비즈니스 (职场与商务, Zhíchǎng yǔ shāngwù)

> 상황: 회의, 이메일, 업무 용어
> 수준: HSK 3~4급 중심
> 단어 수: 25개

---

### 1. 工作 / Gōngzuò / [명사] / 일, 작업

- 한자 풀이:
  - 工: 장인의 도구 형상 → 일, 노동
  - 作: 亻(사람인변) + 乍(잠깐사) → 만들다, 일하다
- HSK 등급: 1급

---

### 2. 公司 / Gōngsī / [명사] / 회사

- 한자 풀이:
  - 公: 八(여덟팔) + 厶(사사사) → 공평하다, 공공의
  - 司: 𠂤(배퇴) + 口(입구) → 관리하다, 관청
- HSK 등급: 2급

---

### 3. 老板 / Lǎobǎn / [명사] / 사장, 보스

- 한자 풀이:
  - 老: 노인이 지팡이를 짚은 모양 → 늙다, 오래된
  - 板: 木(나무목) + 反(돌이킬반) → 판자, 우두머리
- HSK 등급: 3급

---

### 4. 经理 / Jīnglǐ / [명사] / 매니저, 지배인

- 한자 풀이:
  - 经: 纟(실사변) + 巠(물줄기경) → 지나다, 경영하다
  - 理: 王(구슬옥변) + 里(마을리) → 다스리다, 관리하다
- HSK 등급: 3급

---

### 5. 职员 / Zhíyuán / [명사] / 직원

- 한자 풀이:
  - 职: 耳(귀이) + 只(다만지) → 직무, 직업
  - 员: 口(입구) + 贝(조개패) → 구성원, 인원
- HSK 등급: 3급

---

### 6. 同事 / Tóngshì / [명사] / 동료

- 한자 풀이:
  - 同: 冂(멀경) + 一(한일) + 口(입구) → 같다, 함께
  - 事: 史(역사사) + 口(입구)의 변형 → 일, 업무
- HSK 등급: 3급

---

### 7. 客户 / Kèhù / [명사] / 고객, 거래처

- 한자 풀이:
  - 客: 宀(갓머리) + 各(각각각) → 손님
  - 户: 지게문의 형상 → 집, 가구
- HSK 등급: 4급

---

### 8. 会议 / Huìyì / [명사] / 회의

- 한자 풀이:
  - 会: 人(사람인) + 云(구름운) → 사람들이 모이다, 회합
  - 议: 讠(말씀언변) + 义(옳을의) → 의논하다, 토론하다
- HSK 등급: 3급

---

### 9. 办公室 / Bàngōngshì / [명사] / 사무실

- 한자 풀이:
  - 办: 力(힘력) + 八(여덟팔) → 처리하다, 하다
  - 公: 八(여덟팔) + 厶(사사사) → 공적인, 공무
  - 室: 宀(갓머리) + 至(이를지) → 방, 실내 공간
- HSK 등급: 3급

---

### 10. 电脑 / Diànnǎo / [명사] / 컴퓨터

- 한자 풀이:
  - 电: 田(밭전) + 乚(숨은을) → 전기, 번개
  - 脑: 月(육달월) + 㐫(흉악할흉의 변형) → 뇌
- HSK 등급: 2급

---

### 11. 文件 / Wénjiàn / [명사] / 문서, 파일

- 한자 풀이:
  - 文: 무늬의 형상 → 글, 문서
  - 件: 亻(사람인변) + 牛(소우) → 물건, 문서
- HSK 등급: 3급

---

### 12. 打印 / Dǎyìn / [동사] / 인쇄하다

- 한자 풀이:
  - 打: 扌(손수변) + 丁(장정정) → 치다, 행동을 나타냄
  - 印: 爪(손톱조) + 卩(병부절) → 손으로 누르다, 찍다
- HSK 등급: 3급

---

### 13. 合同 / Hétong / [명사] / 계약서

- 한자 풀이:
  - 合: 亼(삼합집) + 口(입구) → 합치다, 맞추다
  - 同: 冂(멀경) + 一(한일) + 口(입구) → 같다, 함께
- HSK 등급: 4급

---

### 14. 项目 / Xiàngmù / [명사] / 프로젝트, 항목

- 한자 풀이:
  - 项: 工(장인공) + 页(머리혈) → 항목
  - 目: 눈의 형상 → 목록, 항목
- HSK 등급: 4급

---

### 15. 加班 / Jiābān / [동사] / 야근하다, 초과 근무하다

- 한자 풀이:
  - 加: 力(힘력) + 口(입구) → 더하다, 추가하다
  - 班: 王(구슬옥변) + 刂(칼도방) + 王(구슬옥변) → 근무조
- HSK 등급: 4급

---

### 16. 工资 / Gōngzī / [명사] / 급여, 임금

- 한자 풀이:
  - 工: 장인의 도구 → 일, 노동
  - 资: 次(버금차) + 贝(조개패) → 자금, 돈
- HSK 등급: 3급

---

### 17. 出差 / Chūchāi / [동사] / 출장가다

- 한자 풀이:
  - 出: 凵(입벌릴감) + 山(메산) → 나가다, 출발하다
  - 差: 羊(양양) + 工(장인공)의 변형 → 보내다, 파견하다
- HSK 등급: 4급

---

### 18. 面试 / Miànshì / [명사/동사] / 면접, 면접 보다

- 한자 풀이:
  - 面: 面(얼굴면) → 얼굴, 직접 대면
  - 试: 讠(말씀언변) + 式(법식) → 시험하다, 시험 보다
- HSK 등급: 4급

---

### 19. 请假 / Qǐngjià / [동사] / 휴가를 신청하다

- 한자 풀이:
  - 请: 讠(말씀언변) + 青(푸를청) → 정중히 요청하다, 청하다
  - 假: 亻(사람인변) + 叚(빌릴가) → 휴가, 빌리다
- HSK 등급: 4급

---

### 20. 上班 / Shàngbān / [동사] / 출근하다

- 한자 풀이:
  - 上: 위쪽 방향을 가리키는 지사 → 오르다, 가다
  - 班: 王(구슬옥변) + 刂(칼도방) + 王(구슬옥변) → 근무조
- HSK 등급: 2급

---

### 21. 下班 / Xiàbān / [동사] / 퇴근하다

- 한자 풀이:
  - 下: 아래 방향을 가리키는 지사 → 내려가다, 끝나다
  - 班: 王(구슬옥변) + 刂(칼도방) + 王(구슬옥변) → 근무조
- HSK 등급: 2급

---

### 22. 名片 / Míngpiàn / [명사] / 명함

- 한자 풀이:
  - 名: 夕(저녁석) + 口(입구) → 어두울 때 입으로 이름을 묻다 → 이름
  - 片: 쪼갠 나무 조각의 형상 → 조각, 카드
- HSK 등급: 3급

---

### 23. 邮箱 / Yóuxiāng / [명사] / 이메일 주소, 우편함

- 한자 풀이:
  - 邮: 由(말미암을유) + 阝(우부변) → 우편, 우송
  - 箱: ⺮(대나무죽) + 相(서로상) → 상자. 相은 소리 요소
- HSK 등급: 3급

---

### 24. 附件 / Fùjiàn / [명사] / 첨부파일

- 한자 풀이:
  - 附: 阝(좌부변) + 付(줄부) → 붙다, 첨부하다
  - 件: 亻(사람인변) + 牛(소우) → 물건, 문서
- HSK 등급: 4급

---

### 25. 回复 / Huífù / [동사] / 회신하다, 답장하다

- 한자 풀이:
  - 回: 口(입구) + 口(입구) → 돌아오다, 답하다
  - 复: 日(날일의 변형) + 夂(뒤져올치) → 다시, 회복하다
- HSK 등급: 3급
