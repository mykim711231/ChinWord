# 여행과 관광 (旅游与观光, Lǚyóu yǔ guānguāng)

> 상황: 관광지, 티켓, 가이드
> 수준: HSK 2~4급 중심
> 단어 수: 25개

---

### 1. 旅行 / lǚxíng / [명사/동사] / 여행(하다)

- 한자 풀이:
  - 旅: 方(모방) + 㐱(무리진) → 여행하다, 나그네
  - 行: 彳(두인변) + 亍 → 가다, 행하다
- HSK 등급: 2급

---

### 2. 游客 / yóukè / [명사] / 관광객

- 한자 풀이:
  - 游: 氵(삼수변) + 方(모방) + 斿 → 헤엄치다, 놀다
  - 客: 宀(갓머리) + 各(각각각) → 손님
- HSK 등급: 3급

---

### 3. 景点 / jǐngdiǎn / [명사] / 관광지, 명소

- 한자 풀이:
  - 景: 日(날일) + 京(서울경) → 경치, 풍경
  - 点: 占(점령할점) + 灬(연화발) → 점, 장소
- HSK 등급: 4급

---

### 4. 门票 / ménpiào / [명사] / 입장권

- 한자 풀이:
  - 门: 门(문문) → 문
  - 票: 罒(그물망변) + 示(보일시) → 표, 티켓
- HSK 등급: 3급

---

### 5. 导游 / dǎoyóu / [명사] / 가이드, 안내원

- 한자 풀이:
  - 导: 巳(뱀사) + 寸(마디촌) → 이끌다, 안내하다
  - 游: 氵(삼수변) + 方(모방) + 斿 → 놀다, 여행하다
- HSK 등급: 3급

---

### 6. 护照 / hùzhào / [명사] / 여권

- 한자 풀이:
  - 护: 扌(손수변) + 户(지게호) → 보호하다
  - 照: 昭(밝을소) + 灬(연화발) → 비추다, 증명
- HSK 등급: 3급

---

### 7. 签证 / qiānzhèng / [명사] / 비자

- 한자 풀이:
  - 签: ⺮(대죽) + 佥(모두첨) → 서명하다, 표
  - 证: 讠(말씀언변) + 正(바를정) → 증명, 증서
- HSK 등급: 4급

---

### 8. 海关 / hǎiguān / [명사] / 세관

- 한자 풀이:
  - 海: 氵(삼수변) + 每(매양매) → 바다
  - 关: 丷(여덟팔변) + 天(하늘천) → 관문, 닫다
- HSK 등급: 4급

---

### 9. 行李 / xíngli / [명사] / 짐, 수하물

- 한자 풀이:
  - 行: 彳(두인변) + 亍 → 가다, 행하다
  - 李: 木(나무목) + 子(아들자) → 오얏(자두)
- HSK 등급: 2급

---

### 10. 行李箱 / xínglixiāng / [명사] / 캐리어, 여행 가방

- 한자 풀이:
  - 行: 彳(두인변) + 亍 → 가다
  - 李: 木(나무목) + 子(아들자) → 오얏
  - 箱: ⺮(대죽) + 相(서로상) → 상자

---

### 11. 翻译 / fānyì / [명사/동사] / 번역(하다), 통역(하다)

- 한자 풀이:
  - 翻: 番(차례번) + 羽(깃우) → 뒤집다, 번역하다
  - 译: 讠(말씀언변) + 又(또우) + 一(한일) → 번역하다
- HSK 등급: 3급

---

### 12. 预订 / yùdìng / [동사] / 예약하다

- 한자 풀이:
  - 预: 予(나여) + 页(머리혈) → 미리, 예상하다
  - 订: 讠(말씀언변) + 丁(못정) → 정하다, 예약하다
- HSK 등급: 3급

---

### 13. 出发 / chūfā / [동사] / 출발하다

- 한자 풀이:
  - 出: 凵(입벌릴감) + 山(메산) → 나가다
  - 发: 丿(삐침) + 又(또우) → 보내다, 출발하다
- HSK 등급: 2급

---

### 14. 到达 / dàodá / [동사] / 도착하다

  - 达: 辶(책받침) + 大(큰대) → 이르다, 도달하다
- HSK 등급: 3급

---

### 15. 拍照 / pāizhào / [동사] / 사진을 찍다

- 한자 풀이:
  - 拍: 扌(손수변) + 白(흰백) → 치다, 찍다
  - 照: 昭(밝을소) + 灬(연화발) → 비추다, 사진

---

### 16. 相机 / xiàngjī / [명사] / 카메라

---

### 17. 纪念品 / jìniànpǐn / [명사] / 기념품
