# 숙박과 호텔 (住宿与酒店, Zhùsù yǔ jiǔdiàn)

> 상황: 체크인, 객실, 서비스 요청
> 수준: HSK 2~3급 중심
> 단어 수: 25개

---

### 1. 酒店 / Jiǔdiàn / [명사] / 호텔

- 한자 풀이:
  - 酒: 氵(삼수변) + 酉(닭유) → 술, 주류. 酉는 술독의 형상
  - 店: 广(엄호) + 占(차지할점) → 가게, 숙소
- HSK 등급: 2급

---

### 2. 房间 / Fángjiān / [명사] / 객실, 방

- 한자 풀이:
  - 房: 户(지게호) + 方(모방방) → 방, 집. 方은 소리 요소
  - 间: 门(문문) + 日(날일) → 문 사이로 햇살이 드는 틈 → 공간, 방
- HSK 등급: 1급

---

### 3. 预订 / Yùdìng / [동사] / 예약하다

- 한자 풀이:
  - 预: 予(줄여) + 页(머리혈) → 미리, 사전에. 予는 소리 요소
  - 订: 讠(말씀언변) + 丁(장정정) → 말로 약속을 정하다, 예약하다
- HSK 등급: 4급

---

### 4. 住 / Zhù / [동사] / 숙박하다, 살다

- 한자 풀이:
  - 住: 亻(사람인변) + 主(주인주) → 사람이 일정한 곳에 머무르다
- HSK 등급: 1급

---

### 5. 钥匙 / Yàoshi / [명사] / 열쇠

- 한자 풀이:
  - 钥: 钅(쇠금변) + 月(달월) → 쇠로 만든 열쇠. 月은 소리 요소
  - 匙: 是(옳을시)의 변형 + 匕(비수비) → 숟가락, 자물쇠를 여는 도구
- HSK 등급: 3급

---

### 6. 房卡 / Fángkǎ / [명사] / 룸키, 카드키

- 한자 풀이:
  - 房: 户(지게호) + 方(모방방) → 방
  - 卡: 上(위상) + 下(아래하)의 결합 → 카드, 막히다
- HSK 등급: 3급

---

### 7. 前台 / Qiántái / [명사] / 프런트, 접수대

- 한자 풀이:
  - 前: 䒑 + 月(육달월) + 刂(칼도방) → 앞. 배가 나아가는 모습에서 유래
  - 台: 厶(사사) + 口(입구) → 높고 평평한 대, 플랫폼
- HSK 등급: 3급

---

### 8. 护照 / Hùzhào / [명사] / 여권

- 한자 풀이:
  - 护: 扌(손수변) + 户(지게호) → 손으로 보호하다, 지키다
  - 照: 昭(빛날소) + 灬(불화밑) → 비추다, 증명하다 → 증명서
- HSK 등급: 3급

---

### 9. 登记 / Dēngjì / [동사] / 등록하다, 체크인하다

- 한자 풀이:
  - 登: 癶(등질발) + 豆(콩두) → 위에 오르다 → 기록하다, 등재하다
  - 记: 讠(말씀언변) + 己(몸기) → 말로 기록하다, 적다
- HSK 등급: 4급

---

### 10. 退房 / Tuìfáng / [동사] / 체크아웃하다

- 한자 풀이:
  - 退: 辶(책받침) + 艮(괘이름간) → 물러나다, 뒤로 돌아가다
  - 房: 户(지게호) + 方(모방방) → 방. 방을 비우고 나가다
- HSK 등급: 3급

---

### 11. 行李 / Xíngli / [명사] / 짐, 수하물

- 한자 풀이:
  - 行: 彳(두인변) + 亍(머무를축) → 가다, 다니다
  - 李: 木(나무목) + 子(아들자) → 오얏. 行李에서 李는 소리 요소
- HSK 등급: 3급

---

### 12. 电梯 / Diàntī / [명사] / 엘리베이터

- 한자 풀이:
  - 电: 田(밭전) + 乚(숨은을) → 전기, 번개
  - 梯: 木(나무목) + 弟(아우제) → 사다리, 계단
- HSK 등급: 3급

---

### 13. 空调 / Kōngtiáo / [명사] / 에어컨

- 한자 풀이:
  - 空: 穴(구멍혈) + 工(장인공) → 비다, 공기, 하늘
  - 调: 讠(말씀언변) + 周(두루주) → 조절하다, 고르게 하다
- HSK 등급: 3급

---

### 14. 热水 / Rèshuǐ / [명사] / 온수, 뜨거운 물

- 한자 풀이:
  - 热: 扌(손수변) + 丸(알환) + 灬(불화밑) → 손으로 만질 수 없을 만큼 뜨겁다
  - 水: 물줄기의 형상 → 물
- HSK 등급: 2급

---

### 15. 上网 / Shàngwǎng / [동사] / 인터넷에 접속하다

- 한자 풀이:
  - 上: 위쪽 방향을 가리키는 지사 → 오르다, 접속하다
  - 网: 그물의 형상 → 그물망, 인터넷
- HSK 등급: 3급

---

### 16. 无线网 / Wúxiànwǎng / [명사] / 무선 인터넷, 와이파이

- 한자 풀이:
  - 无: 𠂉 + 儿(사람인)의 변형 → 없다, 없이
  - 线: 纟(실사변) + 戋(작을전) → 줄, 선
  - 网: 그물의 형상 → 그물망, 인터넷
- HSK 등급: 4급

---

### 17. 打扫 / Dǎsǎo / [동사] / 청소하다

- 한자 풀이:
  - 打: 扌(손수변) + 丁(장정정) → 치다, 행동을 나타내는 접두사
  - 扫: 扌(손수변) + 彐(튼가죽) → 쓸다, 청소하다
- HSK 등급: 3급

---

### 18. 毛巾 / Máojīn / [명사] / 수건

- 한자 풀이:
  - 毛: 털의 형상 → 터럭, 모직물
  - 巾: 천의 형상 → 수건
- HSK 등급: 2급

---

### 19. 早餐 / Zǎocān / [명사] / 아침식사

- 한자 풀이:
  - 早: 日(날일) + 十(열십) → 이르다, 아침
  - 餐: 又(또우) + 食(먹을식) → 손으로 음식을 먹다, 식사
- HSK 등급: 2급

---

### 20. 床 / Chuáng / [명사] / 침대

- 한자 풀이:
  - 床: 广(엄호) + 木(나무목) → 나무로 만든 침대, 평상
- HSK 등급: 1급

---

### 21. 卫生间 / Wèishēngjiān / [명사] / 화장실

- 한자 풀이:
  - 卫: 卩(병부절) + 一(한일) → 지키다, 보호하다
  - 生: 牛(소우) + 一(한일) → 살다, 나다. 卫生은 "위생"
  - 间: 门(문문) + 日(날일) → 공간, 방
- HSK 등급: 2급

---

### 22. 洗澡 / Xǐzǎo / [동사] / 샤워하다, 목욕하다

- 한자 풀이:
  - 洗: 氵(삼수변) + 先(먼저선) → 물로 씻다
  - 澡: 氵(삼수변) + 喿(지저귈조) → 물로 목욕하다. 喿는 소리 요소
- HSK 등급: 2급

---

### 23. 叫醒 / Jiàoxǐng / [동사] / 깨우다, 모닝콜 하다

- 한자 풀이:
  - 叫: 口(입구) + 丩(얽힐구) → 입으로 부르다, 외치다
  - 醒: 酉(닭유) + 星(별성) → 술에서 깨다, 잠에서 깨어나다. 星은 소리 요소
- HSK 등급: 4급

---

### 24. 寄存 / Jìcún / [동사] / 맡기다, 보관하다

- 한자 풀이:
  - 寄: 宀(갓머리) + 奇(기이할기) → 남의 집에 의탁하다, 부치다
  - 存: 子(아들자) + 丨(뚫을곤) → 존재하다, 보관하다
- HSK 등급: 5급

---

### 25. 发票 / Fāpiào / [명사] / 영수증, 인보이스

- 한자 풀이:
  - 发: 丿(삐침) + 犮(땅이름발) → 보내다, 발행하다
  - 票: 西(서녘서) + 示(보일시) → 증서, 증표
- HSK 등급: 4급
