# 인사와 소개 (问候与介绍, Wènhòu yǔ jièshào)

> 상황: 처음 만나는 자리, 일상 인사, 자기소개, 작별 인사
> 수준: HSK 1~2급 중심
> 단어 수: 20개

---

### 1. 你好 / Nǐ hǎo / [인사말] / 안녕하세요

- 한자 풀이:
  - 你: 亻(사람인변) + 尔(너 이) → "너, 그대"라는 뜻의 2인칭 대명사
  - 好: 女(계집녀) + 子(아들자) → "좋다"라는 뜻, 여자와 아이가 함께 있는 모습에서 유래
- HSK 등급: 1급

---

### 2. 谢谢 / Xièxiè / [인사말] / 감사합니다

- 한자 풀이:
  - 谢: 讠(말씀언변) + 射(쏠사) → 말로써 감사를 표현하다. 射는 소리 요소
- HSK 등급: 1급

---

### 3. 对不起 / Duìbuqǐ / [인사말] / 죄송합니다, 미안합니다

- 한자 풀이:
  - 对: 又(오른손우) + 寸(마디촌) → 손으로 마주하다, 대면하다
  - 不: 부정을 나타내는 글자, 새가 하늘로 날아올라 내려오지 않는 모습
  - 起: 走(달릴주) + 巳(뱀사) → 일어나다, 시작하다
- HSK 등급: 1급

---

### 4. 没关系 / Méi guānxi / [관용구] / 괜찮습니다

- 한자 풀이:
  - 没: 氵(삼수변) + 殳(창수) → 물에 잠기다, 없다
  - 关: 丷 + 天(하늘천) → 빗장을 걸다, 관계하다
  - 系: 丿(삐침) + 糸(실사) → 실을 잇다, 연결되다
- HSK 등급: 1급

---

### 5. 再见 / Zàijiàn / [인사말] / 안녕히 가세요, 또 뵙겠습니다

- 한자 풀이:
  - 再: 一 + 冉(나아갈염) → 다시, 거듭
  - 见: 目(눈목)의 변형 + 儿(사람인) → 보다, 만나다
- HSK 등급: 1급

---

### 6. 我叫… / Wǒ jiào… / [자기소개] / 저는 …라고 합니다

- 한자 풀이:
  - 我: 手(손수) + 戈(창과) → 손에 창을 든 나, 1인칭
  - 叫: 口(입구) + 丩 → 입으로 부르다, ~라고 하다
- HSK 등급: 1급

---

### 7. 请问 / Qǐngwèn / [존칭 표현] / 말씀 좀 묻겠습니다

- 한자 풀이:
  - 请: 讠(말씀언변) + 青(푸를청) → 정중히 말씀드리다, 청하다
  - 问: 门(문문) + 口(입구) → 문 앞에서 입으로 묻다
- HSK 등급: 1급

---

### 8. 认识 / Rènshi / [동사] / 알다, 알게 되다

- 한자 풀이:
  - 认: 讠(말씀언변) + 人(사람인) → 말로써 사람을 알아보다
  - 识: 讠(말씀언변) + 只(다만지) → 말로써 알다, 식별하다
- HSK 등급: 1급

---

### 9. 很高兴 / Hěn gāoxìng / [형용사구] / 매우 기쁘다

- 한자 풀이:
  - 很: 彳(두인변) + 艮(괘이름간) → 정도가 심하다, 매우
  - 高: 높은 누각의 모습 → 높다
  - 兴: 臼(절구구)의 변형 + 同(한가지동)의 생략형 → 흥이 일어나다
- HSK 등급: 1급

---

### 10. 欢迎 / Huānyíng / [인사말] / 환영합니다

- 한자 풀이:
  - 欢: 又(또우) + 欠(하품흠) → 기쁘다, 즐겁다
  - 迎: 辶(책받침) + 卬(나앙) → 마중 나가 맞이하다
- HSK 등급: 1급

---

### 11. 您贵姓 / Nín guìxìng / [존칭] / 성함이 어떻게 되십니까

- 한자 풀이:
  - 您: 你(너) + 心(마음심) → 상대를 마음에 두는 존칭, "당신"
  - 贵: ⺋ + 一 + 目(눈목) + 贝(조개패) → 귀하다, 존귀하다
  - 姓: 女(계집녀) + 生(날생) → 성씨 (모계 사회의 흔적)
- HSK 등급: 1~2급

---

### 12. 怎么样 / Zěnmeyàng / [의문사] / 어떻습니까?, 어떻게 지내세요?

- 한자 풀이:
  - 怎: 乍(잠깐사) + 心(마음심) → 어떻게, 어찌
  - 么: 丿(삐침) + 厶(사사사) → 작은 것, 의문을 나타내는 어기조사
  - 样: 木(나무목) + 羊(양양) → 모양, 형태
- HSK 등급: 1급

---

### 13. 早上好 / Zǎoshang hǎo / [인사말] / 좋은 아침입니다

- 한자 풀이:
  - 早: 日(날일) + 十(열십) → 아침, 이르다
  - 上: 위를 가리키는 지사자 → 위, ~의 때
  - 好: 女(계집녀) + 子(아들자) → 좋다
- HSK 등급: 1급

---

### 14. 晚上好 / Wǎnshang hǎo / [인사말] / 좋은 저녁입니다

- 한자 풀이:
  - 晚: 日(날일) + 免(면할면) → 저녁
  - 上: 위 → ~의 때
  - 好: 女 + 子 → 좋다
- HSK 등급: 1급

---

### 15. 晚安 / Wǎn'ān / [인사말] / 안녕히 주무세요

- 한자 풀이:
  - 晚: 日(날일) + 免(면할면) → 저녁, 밤
  - 安: 宀(갓머리) + 女(계집녀) → 평안하다
- HSK 등급: 1급

---

### 16. 好久不见 / Hǎojiǔ bújiàn / [인사말] / 오랜만입니다

- 한자 풀이:
  - 好: 女 + 子 → 매우, 꽤
  - 久: 丿 + 乀 → 오래다
  - 不: 부정사
  - 见: 目의 변형 + 儿 → 보다, 만나다
- HSK 등급: 1급

---

### 17. 名字 / Míngzi / [명사] / 이름

- 한자 풀이:
  - 名: 夕(저녁석) + 口(입구) → 이름
  - 字: 宀(갓머리) + 子(아들자) → 글자
- HSK 등급: 1급

---

### 18. 不好意思 / Bù hǎoyìsi / [관용구] / 실례합니다

- 한자 풀이:
  - 不: 부정사
  - 好: 여자 + 아들 → 좋다
  - 意: 音(소리음) + 心(마음심) → 뜻
  - 思: 田(밭전) + 心(마음심) → 생각
- HSK 등급: 2급

---

### 19. 慢走 / Mànzǒu / [인사말] / 살펴 가세요

- 한자 풀이:
  - 慢: 忄(심방변) + 曼(길만) → 천천히
  - 走: 土(흙토) + 龰(발족) → 걷다
- HSK 등급: 2급

---

### 20. 保重 / Bǎozhòng / [인사말] / 건강 조심하세요

- 한자 풀이:
  - 保: 亻(사람인변) + 呆 → 보호하다
  - 重: 千 + 里(마을리) → 소중하다
- HSK 등급: 2급
