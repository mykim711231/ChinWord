# 식당과 음식 (餐厅与饮食, Cāntīng yǔ yǐnshí)

> 상황: 식당에서 주문, 음식 맛 표현, 계산
> 수준: HSK 1~3급 중심
> 단어 수: 20개

---

### 1. 餐厅 / Cāntīng / [명사] / 식당, 레스토랑

- 한자 풀이:
  - 餐: 又(손우) + 食(먹을식) → 손으로 음식을 먹다, 식사
  - 厅: 厂(언덕엄) + 丁(장정정) → 넓은 방, 홀
- HSK 등급: 2급

---

### 2. 菜单 / Càidān / [명사] / 메뉴판

- 한자 풀이:
  - 菜: 艹(초두머리) + 采(캘채) → 채소, 요리
  - 单: 丷 + 甲(갑옷갑)의 변형 → 하나의, 목록
- HSK 등급: 2급

---

### 3. 点菜 / Diǎncài / [동사] / 주문하다

- 한자 풀이:
  - 点: 占(차지할점) + 灬(불화밑) → 점을 찍다, 지정하다
  - 菜: 艹(초두머리) + 采(캘채) → 요리, 반찬
- HSK 등급: 2급

---

### 4. 好吃 / Hǎochī / [형용사] / 맛있다

- 한자 풀이:
  - 好: 女(계집녀) + 子(아들자) → 좋다
  - 吃: 口(입구) + 乞(빌걸) → 입으로 먹다
- HSK 등급: 1급

---

### 5. 服务员 / Fúwùyuán / [명사] / 종업원, 직원

- 한자 풀이:
  - 服: 月(육달월) + 卩(병부절) + 又(또우) → 옷을 입다, 따르다, 복종하다 → 서비스하다
  - 务: 夂(뒤져올치) + 力(힘력) → 힘쓰다, 일, 업무
  - 员: 口(입구) + 贝(조개패) → 구성원, 인원
- HSK 등급: 2급

---

### 6. 筷子 / Kuàizi / [명사] / 젓가락

- 한자 풀이:
  - 筷: ⺮(대나무죽) + 快(빠를쾌) → 대나무로 만든 젓가락. 快는 소리 요소
  - 子: 아기의 모습 → 접미사
- HSK 등급: 2급

---

### 7. 买单 / Mǎidān / [동사] / 계산하다

- 한자 풀이:
  - 买: 罒(그물망머리) + 头(머리두)의 간략형 → 사다, 구입하다
  - 单: 영수증, 계산서 → 菜单(메뉴판)의 单
- HSK 등급: 2급

---

### 8. 辣 / Là / [형용사] / 맵다

- 한자 풀이:
  - 辣: 辛(매울신) + 束(묶을속) → 맵다, 얼얼하다. 辛은 죄인에게 문신하던 바늘에서 유래하여 "맵다"는 감각으로 확장
- HSK 등급: 3급

---

### 9. 热 / Rè / [형용사] / 뜨겁다

- 한자 풀이:
  - 热: 扌(손수변) + 丸(알환) + 灬(불화밑) → 손으로 만질 수 없을 만큼 뜨겁다. 灬은 불을 뜻함
- HSK 등급: 1급

---

### 10. 米饭 / Mǐfàn / [명사] / 쌀밥

- 한자 풀이:
  - 米: 벼 이삭의 낱알 모습 → 쌀
  - 饭: 饣(밥식변) + 反(돌이킬반) → 밥, 식사
- HSK 등급: 1급

---

### 11. 面条 / Miàntiáo / [명사] / 국수

- 한자 풀이:
  - 面: 面(얼굴면) → 표면, 면
  - 条: 夂(뒤져올치) + 木(나무목) → 길고 가는 것, 나뭇가지 → 국수 가닥
- HSK 등급: 2급

---

### 12. 饮料 / Yǐnliào / [명사] / 음료수

- 한자 풀이:
  - 饮: 饣(밥식변) + 欠(하품흠) → 입을 벌려 마시다
  - 料: 米(쌀미) + 斗(말두) → 쌀을 되로 재다 → 재료, 원료
- HSK 등급: 2급

---

### 13. 勺子 / Sháozi / [명사] / 숟가락

- 한자 풀이:
  - 勺: 勹(쌀포) + 丶(점주) → 국자, 숟가락
  - 子: 접미사
- HSK 등급: 3급

---

### 14. 叉子 / Chāzi / [명사] / 포크

- 한자 풀이:
  - 叉: 又(또우) + 丶(점주) → 갈고리 모양 → 포크
  - 子: 접미사
- HSK 등급: 3급

---

### 15. 碗 / Wǎn / [명사] / 그릇, 사발

- 한자 풀이:
  - 碗: 石(돌석) + 宛(굽을완) → 돌로 만든 그릇. 宛은 소리 요소
- HSK 등급: 2급

---

### 16. 杯子 / Bēizi / [명사] / 컵

- 한자 풀이:
  - 杯: 木(나무목) + 不(아닐부) → 나무로 만든 잔. 不은 소리 요소
  - 子: 접미사
- HSK 등급: 2급

---

### 17. 凉 / Liáng / [형용사] / 차갑다, 시원하다

- 한자 풀이:
  - 凉: 冫(얼음빙변) + 京(서울경) → 얼음처럼 차갑다. 京은 소리 요소
- HSK 등급: 2급

---

### 18. 甜 / Tián / [형용사] / 달다

- 한자 풀이:
  - 甜: 舌(혀설) + 甘(달감) → 혀로 달콤함을 느끼다
- HSK 등급: 2급

---

### 19. 咸 / Xián / [형용사] / 짜다

- 한자 풀이:
  - 咸: 戌(개술) + 口(입구) → 소금기, 짠 맛. 원래 "모두"라는 뜻에서 맛 표현으로 확장
- HSK 등급: 3급

---

### 20. 汤 / Tāng / [명사] / 국, 탕

- 한자 풀이:
  - 汤: 氵(삼수변) + 昜(볕양) → 뜨거운 물 → 국. 昜은 소리 요소
- HSK 등급: 2급
