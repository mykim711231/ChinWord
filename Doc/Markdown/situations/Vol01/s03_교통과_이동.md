# 교통과 이동 (交通与出行, Jiāotōng yǔ chūxíng)

> 상황: 택시, 지하철, 버스, 길 묻기
> 수준: HSK 1~3급 중심
> 단어 수: 25개

---

### 1. 车 / Chē / [명사] / 차

- 한자 풀이:
  - 车: 车(수레거) → 바퀴 달린 탈것, 차량
- HSK 등급: 1급

---

### 2. 出租车 / Chūzūchē / [명사] / 택시

- 한자 풀이:
  - 出: 凵(입벌릴감) + 山(메산) → 나가다, 나오다
  - 租: 禾(벼화) + 且(또차) → 빌리다, 임대하다
  - 车: 车(수레거) → 차
- HSK 등급: 2급

---

### 3. 公共汽车 / Gōnggòng qìchē / [명사] / 버스

- 한자 풀이:
  - 公: 八(여덟팔) + 厶(사사사) → 공공의, 공적인
  - 共: 廿(스물입) + 八(여덟팔) + 廾(스물입변) → 함께, 공동
  - 汽: 氵(삼수변) + 气(기운기) → 증기, 수증기
  - 车: 车(수레거) → 차
- HSK 등급: 2급

---

### 4. 地铁 / Dìtiě / [명사] / 지하철

- 한자 풀이:
  - 地: 土(흙토) + 也(이을야) → 땅
  - 铁: 钅(쇠금변) + 失(잃을실) → 쇠, 철
- HSK 등급: 2급

---

### 5. 火车 / Huǒchē / [명사] / 기차

- 한자 풀이:
  - 火: 火(불화) → 불(불꽃이 타오르는 모양)
  - 车: 车(수레거) → 차
- HSK 등급: 1급

---

### 6. 飞机 / Fēijī / [명사] / 비행기

- 한자 풀이:
  - 飞: 飞(날비) → 날다(새가 날개를 펼친 모양)
  - 机: 木(나무목) + 几(안석궤) → 기계
- HSK 등급: 1급

---

### 7. 自行车 / Zìxíngchē / [명사] / 자전거

- 한자 풀이:
  - 自: 自(스스로자) → 스스로, 자신(코를 가리킨 모양에서 유래)
  - 行: 彳(두인변) + 亍(머무를축) → 가다, 다니다
  - 车: 车(수레거) → 차
- HSK 등급: 2급

---

### 8. 走路 / Zǒulù / [동사] / 걷다

- 한자 풀이:
  - 走: 走(달릴주) → 걷다, 달리다(사람이 팔을 흔들며 달리는 모양)
  - 路: 足(발족) + 各(각각각) → 길
- HSK 등급: 1급

---

### 9. 开车 / Kāichē / [동사] / 운전하다

- 한자 풀이:
  - 开: 开(열개) → 열다(문빗장을 여는 모양)
  - 车: 车(수레거) → 차
- HSK 등급: 1급

---

### 10. 车站 / Chēzhàn / [명사] / 정류장

- 한자 풀이:
  - 车: 车(수레거) → 차
  - 站: 立(설립) + 占(차지할점) → 서다, 정류장(사람이 서 있는 곳)
- HSK 등급: 2급

---

### 11. 机场 / Jīchǎng / [명사] / 공항

- 한자 풀이:
  - 机: 木(나무목) + 几(안석궤) → 기계, 비행기
  - 场: 土(흙토) + 昜(햇살양) → 장소, 마당
- HSK 등급: 2급

---

### 12. 票 / Piào / [명사] / 표, 티켓

- 한자 풀이:
  - 票: 覀(덮을아) + 示(보일시) → 표, 증표(원래는 불에 태워 신에게 알리는 표시)
- HSK 등급: 1급

---

### 13. 路 / Lù / [명사] / 길

- 한자 풀이:
  - 路: 足(발족) + 各(각각각) → 길(사람이 가는 통로)

---

### 14. 红绿灯 / Hónglǜdēng / [명사] / 신호등

- 한자 풀이:
  - 红: 纟(실사변) + 工(장인공) → 붉다
  - 绿: 纟(실사변) + 录(기록록) → 녹색, 푸르다
  - 灯: 火(불화) + 丁(못정) → 등, 불빛
- HSK 등급: 2급

---

### 15. 十字路口 / Shízìlùkǒu / [명사] / 사거리

- 한자 풀이:
  - 十: 十(열십) → 열, 십자 모양
  - 字: 宀(갓머리) + 子(아들자) → 글자
  - 路: 足(발족) + 各(각각각) → 길
  - 口: 口(입구) → 입, 입구
- HSK 등급: 3급

---

### 16. 左边 / Zuǒbian / [명사] / 왼쪽

- 한자 풀이:
  - 左: 𠂇(왼손좌) + 工(장인공) → 왼쪽(왼손이 장인의 일을 도움)
  - 边: 辶(책받침) + 力(힘력) → 쪽, 가장자리
- HSK 등급: 1급

---

### 17. 右边 / Yòubian / [명사] / 오른쪽

- 한자 풀이:
  - 右: 𠂇(왼손좌) + 口(입구) → 오른쪽(입으로 오른손을 부름)
  - 边: 辶(책받침) + 力(힘력) → 쪽

---

### 18. 一直走 / Yìzhí zǒu / [동사구] / 직진하다

- 한자 풀이:
  - 一: 一(한일) → 하나, 한결같이
  - 直: 十(열십) + 目(눈목) + 一(한일) → 곧다, 직선(눈으로 똑바로 봄)
  - 走: 走(달릴주) → 걷다, 가다
- HSK 등급: 2급

---

### 19. 拐弯 / Guǎiwān / [동사] / 방향을 틀다

- 한자 풀이:
  - 拐: 扌(손수변) + 另(다를령) → 돌리다, 방향을 바꾸다
  - 弯: 亦(또역, 변형) + 弓(활궁) → 굽다, 구부러지다
- HSK 등급: 3급
