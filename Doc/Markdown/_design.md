## 0. 결정사항 요약 (Decisions)

| 항목 | 결정 |
|---|---|
| 접근 제어 | **완전 공개** — URL만 알면 접근, 로그인 없음 |

| 알림 | 웹 푸시 미사용 |

## 1. 프로젝트 개요

### 1.1 목적
북경 표준어(普通话)의 실생활 어휘와 자주 사용되는 고사성어(成语)를 상황별·주제별로 학습할 수 있는 PWA를 제작한다. 앱스토어 없이 URL 한 줄로 배포하며, 오프라인·음성·필순·복습(플래시카드)을 모두 지원한다.

### 1.2 핵심 가치 제안
- **언제든** 인터넷 없이도 학습 (PWA 오프라인)
- **누구나** 설치 장벽 없이 시작 (앱스토어 X, 로그인 X)
- **들으며** 학습 (이어듣기 — 연속 TTS 재생)
- **보며** 학습 (필순 애니메이션, 한자 풀이)
- **꾸준히** 복습 (플래시카드 Leitner SRS)

### 1.3 비목표 (Out of Scope, Phase 1)
- 사용자 계정 / 클라우드 동기화
- 채점·시험·퀴즈 기능
- 멀티 디바이스 진도 공유
- 동영상 강의
- 웹 푸시 알림
- 사용자 분석/추적 (개인정보 부담 0, 로그 없음)
- 예문(例句) — 저작권 리스크 방지

### 1.4 저작권 & 안내문 (필수)

**Footer (모든 화면 하단):**
```
© ChinWord. All content is self-created. All Rights Reserved.
```

**About 페이지 (설정 → 정보):**
> ### 콘텐츠 출처 및 이용 안내
> 본 애플리케이션에서 제공하는 모든 중국어 단어·뜻풀이·필순 정보는
> 공개 도메인 자원(강희자전, HSK 공개 어휘 목록 등)을 기반으로
> 자체 편집·작성되었습니다.
> 모든 한자 풀이와 예문은 직접 창작되었으며,
> 무단 복제 및 상업적 이용을 금합니다.

## 2. 사용자 페르소나 & 시나리오

### 2.1 페르소나

| 페르소나 | 특징 | 주요 사용 맥락 |
|---|---|---|
| **P1 김직장인 (30대 남)** | 출퇴근 지하철, 중국 출장 준비, 짧은 틈새 시간 활용 | 상황별 단어, 빠른 이어듣기, 플래시카드 |
| **P2 이대학생 (20대 여)** | 중국어 전공 준비, HSK 4급 목표, 데스크톱 + 모바일 병행 | 필순 확인, 한자 풀이 상세 확인, 고사성어 암기 |
| **P3 박은퇴자 (60대 남)** | 중국 여행 준비, 시력 약화, Android 폰 사용 | 큰글씨 모드, 천천히 듣기, 한글 뜻 위주 |

### 2.2 핵심 시나리오 (User Journey)
1. 사용자가 공유 링크로 URL 열기 → 브라우저에서 PWA 접속
2. 첫 진입 시 "홈화면에 추가" 가이드 → 설치
3. 홈 → 상황별 단어 목록 탐색 또는 고사성어 주제 선택
4. 단어 상세 → 한자·병음·뜻 확인 → 🔊 눌러 발음 듣기
5. 필순 애니메이션으로 획순 학습
6. 모르는 단어는 플래시카드에 추가 → Leitner SRS로 복습
7. 이어듣기 모드로 여러 단어 연속 청취

## 5. 콘텐츠 데이터 모델

### 5.1 마크다운 → JSON 변환

`scripts/build-content.ts`가 `Doc/Markdown/**/*.md`를 읽어 다음 구조로 변환:

```ts
// VocabEntry — 상황별 단어
export type VocabEntry = {
  id: string;              // "s01_01"
  word: string;            // "你好"
  pinyin: string;          // "Nǐ hǎo"
  pos: string;             // "인사말"
  meaning: string;         // "안녕하세요"
  hanjaBreakdown: string;  // "你: 亻+尔 → 너" (한자 풀이)
  hskLevel: number;        // 1~6 (HSK 등급)
};
// 필순은 PWA에서 hanzi-writer로 표시 — SVG 애니메이션

// IdiomEntry — 고사성어
export type IdiomEntry = {
  id: string;              // "i01_01"
  word: string;            // "温故知新"
  pinyin: string;          // "Wēn gù zhī xīn"
  pos: string;             // "성어"
  meaning: string;         // "옛것을 익히고 새것을 안다"
  sourceText: string;      // 원문 (한자 원문 + 병음)
  origin: string;          // 유래 설명 (한국어)
  charBreakdown: CharBreakdown[];  // 글자별 풀이
  synonyms: string[];      // 유의 성어
};

export type CharBreakdown = {
  char: string;            // "温"
  pinyin: string;          // "wēn"
  meaning: string;         // "따뜻할 온, 익히다"
};

// VocabGroup — 상황별 단어 묶음
export type VocabGroup = {
  id: string;              // "s01"
  title: string;           // "인사와 소개"
  titlePinyin: string;     // "Wènhòu yǔ jièshào"
  entries: VocabEntry[];   // 10~15개
};

// IdiomGroup — 고사성어 묶음
export type IdiomGroup = {
  id: string;              // "i01"
  title: string;           // "학습과 노력"
  entries: IdiomEntry[];   // 6~8개
};

// ContentBundle — 최상위
export type ContentBundle = {
  buildHash: string;
  phases: Phase[];              // 3단계
  vocabGroups: VocabGroup[];   // 18개 (s01~s18, 440단어)
  idiomGroups: IdiomGroup[];   // 9개 (i01~i09, 72성어)
};
```

### 5.2 파서 규칙

- 소스 디렉터리: `Doc/Markdown/Phase01/`, `Doc/Markdown/Phase02/`, `Doc/Markdown/Phase03/`
- 각 Phase 폴더의 `situations/` 및 `idioms/` 하위를 재귀적으로 탐색
- Phase 태그를 각 그룹에 추가하여 단계별 필터링 지원
- `### N. 汉字 / 병음 / [품사] / 한국어 뜻` → VocabEntry
- 하위 항목: `- 한자 풀이: ...` → hanjaBreakdown, `- HSK 등급: N급` → hskLevel
- 고사성어: `### N. 成语 / 병음 / [성어] / 한국어 뜻` → IdiomEntry
- 하위 항목: `- 원문: ...` → sourceText, `- 유래: ...` → origin, `- 글자별 풀이:` 아래 리스트 → charBreakdown, `- 유의어:` 아래 리스트 → synonyms

### 5.3 빌드 산출물

- `app/src/data/vocab-groups.json` (Phase01·02·03 병합, 상황별 18그룹, 440단어)
- `app/src/data/idiom-groups.json` (Phase01·02·03 병합, 주제별 9그룹, 72성어)
- `app/src/data/vocab-meta.json` (그룹 타이틀 + Phase 태그, 약 2KB)
- `app/src/data/search-index.json` (MiniSearch 색인)

- [▶ 재생]: hanzi-writer로 해당 한자 획순 애니메이션 1회 재생
- [⟳ 반복]: 획순 애니메이션 반복 재생
- 좌우 스와이프: 이전/다음 단어 이동
- 필순 데이터: hanzi-writer-data (9000자+, MD에 텍스트 필순 미포함)
